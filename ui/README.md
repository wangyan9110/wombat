# Web 前端

中文 | [English](README.en.md)

`@wombat/ui` 是 React / TypeScript / Vite 展示模块。`App` 注入 `UsageClient`，浏览器入口装配 HTTP 和本次访问令牌。扫描、计价、汇总、分组与匹配排序由 Rust 提供，不迁移旧 TUI 页面。

## 运行

从仓库根目录构建并启动：

```sh
corepack pnpm build
node dist/wombat.js web --lang zh
```

打开输出链接；页面读取本机记录，Ctrl+C 停止服务。可用 `--root` 指定来源、`--port` 指定端口。服务只监听 loopback，访问令牌留在当前浏览器会话，重启服务后需要新链接。

## 页面与实现边界

| 页面 | 已接入 | 明确边界 |
|---|---|---|
| 外壳 | 目录范围 × 概览 / 任务 / 指令 / 扩展 / 优化；深浅主题、中英切换、窄屏导航；桌面侧栏常驻账户级额度摘要，窄屏顶部单一入口 | 账户额度不随项目或日期改变；未知、过期和多窗口不合成为0%或单一比例；历史目录证据不等于项目注册 |
| 概览 | Token 与金额同屏、缓存命中率、时段趋势、目录/模型排行、统一右侧详情、近期/高用量任务与优化摘要 | 未知不作零；金额为标准 API 等价估算 |
| 任务 | 用途说明、当前筛选的任务/Token/API估算汇总；标题/目录/完整 ID 搜索，明确关联轮次数、相关建议标记、匹配消耗/最近匹配排序、分页、ID 定位及最近/全部/最高用量轮次入口 | 轮次数只来自当前列表范围中有明确关联的记录；缺失显示未知，建议只在既有证据可关联时显示；不展示完整对话正文 |
| 轮次 | 全对话/匹配用量、历史模型与强度、执行状态及原生/派生耗时、内核相对时间轴或列表降级、固定版本证据与安全分享预览 | 没有轮次关联的计量单列，不猜测操作费用；Skill/MCP 使用总计、对象页及操作证据固定同一快照，全轮未知次数与已关联次数分列 |
| 来源 | 实际来源身份、目录、能力、覆盖状态与问题 | 不宣称连接健康，不修改来源配置 |
| 金额依据与价表 | 历史计价版本、类别费用、官方来源、标准/长上下文档和真实更新 | 价表页展示当前价表；固定快照不随更新重算 |
| 配置 | 类型/证据/搜索筛选、完整汇总、详情、固定版本证据分页、配置与回合双向跳转、跨目录关联 | 历史中已观察项目可直接切换读取，额外目录由宿主添加；历史版本未知、覆盖缺口均明确；完整内容按固定方法估算 Token，码点/字节和历史次数独立 |
| 优化 | 对象级静态建议、待处理/记录、保留/不适用、重新显示及直接复查；详情按问题、位置与证据、建议处理、关联用量、计算口径、处理记录阅读 | 格式问题公开文件与行列、字段、原因和安全的结构示例，不保存字段原值；决定与逐规则检查事实独立，不预测节省 |

页面结构按已审查的 HTML/CSS 与渲染函数改写成 React；[样式](src/reference.css)保持原始字节，布局适配单列在 `style.css`。必要视觉资产与哈希见[清单](reference-manifest.json)。构建和测试不依赖外部设计仓库，也不打包演示数据或模拟配置操作。

与设计样本的有意差异：侧栏展示实际目录和未知归属；来源按原型弹窗查看，另保留地址直达入口；搜索提交后查询；语言切换替代演示设置；优化显示有依据的静态提醒，建议支持直接复查与明确用户决定。实际记录数、模型、价格与尺寸随真实内容变化，样式复用不代表所有动态内容逐像素一致。

## 内部职责

概览、任务与相关配置共用内部返回路径，保留每一层的筛选、轮次及操作记录分页。`navigation.ts` 和 `useNavigation.ts` 管理浏览位置：内存最多保留 24 个视图，当前历史项保存有界滚动、展开与焦点信息，刷新可恢复当前位置。恢复等待异步内容到达，用户操作立即优先；不保存对话正文。该机制不将用量弹窗保存为跨页业务记录。

`App`装配路由与共享上下文；`shell/`负责导航、日期/筛选和来源；`config/`负责证据详情及测量标签；`optimize/`负责建议详情与规则依据。查询生命周期保留在对应Hook，业务规则与用户记录持久化仍在Rust；页面仅使用当前路由和独立筛选状态。

## 状态与查询

日期包含首尾两天，调用时转换为排他结束边界；全部包含日期未知记录并标注；切日/周/月不改日期。全部输入包含缓存读写，推理是输出子集，保持旧 `tokens.input` 的非缓存含义。新派生值及目录/模型分组来自生成契约；CLI 提供相同查询。

URL 保存范围、筛选、搜索、排序、趋势/对话/轮次分页及选择，浏览器前进/后退恢复状态。页面可见时，每次查询完成后约3秒探测当前版本；版本未变不重读列表，隐藏时暂停，重新可见时补查。阅读对话或展开时段明细时保留当前版本，只提示新数据，由用户应用；应用更新保留同范围明细展开和分页。同步未完成或失败会显示旧结果状态并继续重试；主动取消暂停自动跟进，切换查询或重试后恢复。连接凭据失效则停止探测，提示从终端打开最新完整链接。空页面区分未发现日志、来源读取不完整和筛选无匹配，并提供来源、清除筛选及可用日期入口。

主列表和趋势先固定到同一版本再更新；轮次执行过程以外的版本过期会重读一次并提示。轮次执行过程保留旧组，过期后要求显式整组刷新。查询缓存最多16项，仅保留一个版本。轮次默认只看匹配计量，可切换完整上下文并定位原轮次；每页20项，事件每页100项；趋势每页120个时段，时段明细展开后按12个时段分页，模型/强度明细只读取展开的时段。汇总、排序和图表刻度来自完整范围，不从当前页重算；不再遍历全部分页。单个时段的明细仍按内核完整组返回，并受宿主响应上限约束。

失败/取消保留上次完整主视图，同范围旧结果可继续下钻；前一范围结果不能当作新范围继续操作，局部明细失败可独立重试。明细按版本、范围、选择和页码识别，过时响应不能覆盖新查询；范围变化重置明细页。浏览器刷新保留 URL，重新读取版本；主题留在本机浏览器，不持久化结果或完整对话。时段明细和事件分页在组件内，不跨刷新恢复。

## 开发与验证

只依赖客户端公开接口和语言服务，不导入 Node、Tauri、终端或原始来源。静态资产由完整构建复制到 `dist/web/`；修改后重新构建并重启服务。桌面宿主尚未交付，见[架构](../docs/development/architecture.md)。

`corepack pnpm --filter @wombat/ui test` 验证 URL 往返、日期转换、固定版本传输、自动版本跟进、范围失效、过时响应、过期恢复、取消和隐藏暂停；跨语言真值与主链路由集成/端到端测试覆盖。浏览器验收范围及未验收平台见 Git 历史中的验证记录。构建、静态检查不替代真实交互或逐像素比较。

配置路由保存类型、搜索、证据状态、排序、页码、选中项和读取版本；离开或改变查询会取消当前连接并隔离迟到结果。配置页不轮询，显式刷新更新配置与用量；过期提示重新读取。原回合跳转固定其用量版本，返回保留配置位置。配置特有布局在 `src/config.css`，实际范围见[配置契约](../docs/development/contracts.md)。

用量或金额打开同一右侧详情，按时间/模型/项目/相关任务查询固定用量版本；概览金额两位，详情四位，正值低于精度显示阈值。任务列表汇总沿用当前搜索与全局筛选的内核结果，不从当前分页重算；列表轮次数按匹配计量中的明确轮次 ID 去重，来源未提供关联时不显示0。任务构成默认展开、来源折叠；最近、全部、最高用量轮次和已有相关建议位于任务总量下方，按固定版本定位。390px 窄屏先显示列表，进入详情后可返回并保留范围与选择。语言切换保留弹窗和焦点，偏好经 Rust 保存到产品数据目录。

优化按对象合并问题，URL 保留类别、pending/history、建议与独立记录身份、读取版本及决策版本。详情先显示问题与可操作证据，格式诊断给出文件、行列、字段、错误原因，以及不含字段原值的当前结构和正确格式；规则版本、阈值和计算方法折叠显示。定位配置或复制路径后由用户编辑，直接重新检测；首次观察保存原始依据。共用评估组件展示五种检查结果，包括未发现问题时的测量和阈值，并说明证据缺口与原始范围。复查直接消费内核明确的可比／不可比／未知状态，不从当前文件值判定解决。用户决定及原因与本次事实和不可变基线分开展示。Skill/MCP 关联使用次数来自内核投影；零、未知次数、失败操作和完整范围总量均与分页证据区分。无法读取或完整解析时保留原问题，不显示通过。保留/不适用及原因与检查结果分别保存，复查不撤销决定，记录不随派生索引重建丢失。无闲置和空间适配的类别直接说明不可检查。

首次外壳先渲染，再异步恢复偏好；用户选择优先。SYNC_PENDING显示本页等待秒数并自动跟进，取消不宣称停止共享扫描。来源页可在无首个结果时读取启动授权；有任务元数据但无计量时可扩大日期/模型条件进入任务列表。默认近30天保存相对意图，手动日期与固定版本不滚动。

时间趋势仅绘日期已知记录；全部日期总量仍含未知日期，未知日期另有用量详情入口。更新失败时，就近标示上次成功读取时间，原范围/结果保留，范围变更未就绪时仍禁止旧结果冒充新查询。当前共享配置详情按来源展开证据；任务的关联配置与用量详情分别布局并可换行。

## 共用组件预览

运行 `corepack pnpm --filter @wombat/ui preview`，打开 `http://127.0.0.1:5173/preview.html?page=threads&allTime=true`。开发入口向正式 App 注入模拟 UsageClient，不连接 HTTP 宿主、来源日志或原生账户。生产入口不导入预览模块。

预览通过正式组件展示任务、配置与规则样例。账户场景覆盖额度偏低／耗尽、未登录、API Key、不支持、陈旧／过期、部分、多窗口、积分、加载及刷新失败。注入宿主传输后，可在共用界面选择／确认／撤销目录，并复核后发送给 Codex，展示已接收、部分、未知、失败、额度耗尽或不可用结果。目录选择令牌会过期且只能消费一次；发送绑定复核的选择与范围。模拟宿主不调用原生接口、不修改文件，也不模拟执行或解决。切换场景重置选择、授权和规则决定。任务分页／筛选、丰富配置详情、价格及其余首次读取状态尚未完整建模；这是增量迁移，不代表完整原型验收。

通过 `corepack pnpm --filter @wombat/ui exec node --import tsx --test tests/preview.test.ts tests/preview-hosts.test.ts` 检查模拟数据行为及宿主契约。评估与复查模拟数据使用同一公开校验器和正式组件，定向测试覆盖中英两种语言，不运行浏览器。中间阶段使用模块测试和 DOM/交互检查，完整产品集成仍在最终阶段进行。组件与样式只维护一份；新增场景通过模拟数据接入，不另写 HTML 界面。

执行过程预览：在同一开发服务打开 `preview.html?previewModule=execution&lang=zh`。预览注入模拟的 typed UsageClient，使用正式轮次组 hook 和组件；模拟事实通过生成的耗时校验器，不维护另一套展示输入模型。提供完整、时间缺失、进行中、大量操作、空结果、加载和失败场景。

执行过程绑定正在展示的轮次结果 snapshotRef。首次耗时加载时保留用量；刷新保留旧用量/耗时/证据组，两个替换查询确认同版后一起切换，失败保留旧组。目标或范围变化取消本次连接并丢弃迟到结果；版本过期停止新证据读取，提供显式整组刷新。区间导航消费内核不透明页定位；定位不可用时不把第一页当作相关记录。分享另行请求同一固定版本的 share-v1，预览和复制原样返回对象，不加入本机标题或路径。浏览器只展示内核相对轨道、测量、零值、未知和暂定状态，不配对事件或计算汇总。Skill/MCP 使用消费内核完整轮次总计及独立对象／记录页，区分全轮与已关联次数、重放、候选、失败结果和归属未知。分页、取消及过期固定同一快照；过期要求整组刷新。分享只导出数值使用总计，不含对象路径或服务器身份。

独立 mock 与服务端 DOM 渲染检查覆盖固定身份、替换/失败/过期、取消、五种状态、列表降级、并发口径及双语。真实浏览器交互、宽窄屏验收与内核联调仍属于 U19；本增量未运行截图或真实来源验收。
