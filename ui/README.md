# Web 前端

中文 | [English](README.en.md)

`@wombat/ui` 是 React / TypeScript / Vite 展示模块。`App` 注入 `UsageClient`，浏览器入口装配 HTTP 和本次访问令牌。扫描、计价、汇总、分组与匹配排序由 Rust 提供，不迁移旧 TUI 页面。

## 运行

从仓库根目录构建并启动：

```sh
corepack pnpm build
node dist/wombat.js web --lang zh
```

打开输出链接；页面读取本机记录，Ctrl+C 停止服务。可用 `--root` 指定来源、`--port` 指定端口。服务只监听 loopback，访问令牌留在当前浏览器会话，重启服务后需要新链接。

## 页面与实现边界

| 页面 | 已接入 | 明确边界 |
|---|---|---|
| 外壳 | 目录范围 × 用量 / 对话 / 配置 / 优化；深浅主题、中英切换、窄屏导航 | 历史目录证据不等于项目注册；没有把未知归属标成无项目 |
| 用量 | Token 与金额同屏、缓存命中率、时段趋势、目录/模型排行、折叠明细与关联对话 | 未知不作零；金额为标准 API 等价估算 |
| 对话 | 标题/目录/完整 ID 搜索，匹配消耗/最近匹配排序，分页与 ID 定位 | 展示安全元数据，不展示完整对话正文 |
| 轮次 | 全对话/匹配用量、历史模型与强度、折叠来源、时间顺序事件及匹配标记 | 没有轮次关联的计量单列，不猜测操作费用 |
| 来源 | 实际来源身份、目录、能力、覆盖状态与问题 | 不宣称连接健康，不修改来源配置 |
| 金额依据与价表 | 历史计价版本、类别费用、官方来源、标准/长上下文档和真实更新 | 价表页展示当前价表；固定快照不随更新重算 |
| 配置 | 类型/证据/搜索筛选、完整汇总、详情、固定版本证据分页、配置与回合双向跳转、跨目录关联 | 仅显式授权目录；历史版本未知、覆盖不足和内容Token估算不可用均明确显示 |
| 优化 | 共用配置清单提供只读核查 | 自动建议、节省估算、应用与恢复尚未实现 |

页面结构按已审查的 HTML/CSS 与渲染函数改写成 React；[样式](src/reference.css)保持原始字节，布局适配单列在 `style.css`。必要视觉资产与哈希见[清单](reference-manifest.json)。构建和测试不依赖外部设计仓库，也不打包演示数据或模拟配置操作。

与设计样本的有意差异：侧栏展示实际目录和未知归属；来源按原型弹窗查看，另保留地址直达入口；搜索提交后查询；语言切换替代演示设置；优化仅显示真实不可用状态。实际记录数、模型、价格与尺寸随真实内容变化，样式复用不代表所有动态内容逐像素一致。

## 状态与查询

日期包含首尾两天，调用时转换为排他结束边界；切日/周/月不改日期。全部输入包含缓存读写，推理是输出子集，保持旧 `tokens.input` 的非缓存含义。新派生值及目录/模型分组来自生成契约；CLI 提供相同查询。

URL 保存范围、筛选、搜索、排序、趋势/对话/轮次分页及选择，浏览器前进/后退恢复状态。页面可见时，每次查询完成后约3秒探测当前版本；版本未变不重读列表，隐藏时暂停，重新可见时补查。阅读对话或展开时段明细时保留当前版本，只提示新数据，由用户应用；应用更新保留同范围明细展开和分页。同步未完成或失败会显示旧结果状态并继续重试；主动取消暂停自动跟进，切换查询或重试后恢复。连接凭据失效则停止探测，提示从终端打开最新完整链接。空页面区分未发现日志、来源读取不完整和筛选无匹配，并提供来源、清除筛选及可用日期入口。

主列表和趋势先固定到同一版本再更新；版本过期重读一次并提示。查询缓存最多16项，仅保留一个版本。轮次默认只看匹配计量，可切换完整上下文并定位原轮次；每页20项，事件每页100项；趋势每页120个时段，时段明细展开后按12个时段分页，模型/强度明细只读取展开的时段。汇总、排序和图表刻度来自完整范围，不从当前页重算；不再遍历全部分页。单个时段的明细仍按内核完整组返回，并受宿主响应上限约束。

失败/取消保留上次完整主视图并禁止继续下钻，局部明细失败可独立重试。明细按版本、范围、选择和页码识别，过时响应不能覆盖新查询；范围变化重置明细页。浏览器刷新保留 URL，重新读取版本；主题留在本机浏览器，不持久化结果或完整对话。时段明细和事件分页在组件内，不跨刷新恢复。

## 开发与验证

只依赖客户端公开接口和语言服务，不导入 Node、Tauri、终端或原始来源。静态资产由完整构建复制到 `dist/web/`；修改后重新构建并重启服务。桌面宿主尚未交付，见[架构](../docs/development/architecture.md)。

`corepack pnpm --filter @wombat/ui test` 验证 URL 往返、日期转换、固定版本传输、自动版本跟进、范围失效、过时响应、过期恢复、取消和隐藏暂停；跨语言真值与主链路由集成/端到端测试覆盖。浏览器验收范围及未验收平台见[进度](../docs/project/progress.md)。构建、静态检查不替代真实交互或逐像素比较。

配置路由保存类型、搜索、证据状态、排序、页码、选中项和读取版本；离开或改变查询会取消当前连接并隔离迟到结果。配置页不轮询，显式刷新更新配置与用量；过期提示重新读取。原回合跳转固定其用量版本，返回保留配置位置。配置特有布局在 `src/config.css`，实际范围见[配置契约](../docs/development/contracts.md)。
