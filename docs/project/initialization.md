# 初始化与持续发现

中文 | [English](initialization.en.md)

2026-10-04。本文定义首次运行、再次运行和运行中新增项目使用同一套读取流程。它补充[首版规格](specification.md)与[首次运行规则](startup-rules.md)；当前完成情况仍以[架构](../development/architecture.md)和源码为准。

## 目标

Wombat 启动后先恢复可用结果，再增量读取支持的本机 Agent 来源。项目不是需要注册的对象：当可靠会话元数据给出工作目录时，项目进入本机项目目录并自动纳入用量索引。用户切换到这个项目时可以直接读取当前配置，不再进行单独授权。

仅创建一个文件夹不会产生项目证据。Wombat 不扫描整块磁盘猜测项目；新目录在被支持的 Agent 实际使用并写入来源记录后自动出现。未出现在记录中的额外来源或目录仍可通过系统目录选择器添加。

## 统一流程

1. **连接本机服务。** 页面外壳先出现；连接、偏好和账户读取互不阻塞。
2. **发现来源。** 来源适配器检查默认位置、启动参数和已添加来源。原始日志只读。
3. **恢复已提交结果。** 已有索引时先返回最后一次完整提交，后台继续核对变化；旧结果不会因一次更新失败而消失。
4. **增量读取。** 首次运行读取活跃与归档历史；后续只处理新增、追加、替换或删除的来源文件。游标、派生事实和提交版本在同一事务中更新。
5. **建立项目目录。** 从可靠的会话工作目录提取项目观察。新项目追加，已有项目保持身份和位置；归属不明的记录继续保持未归属。
6. **发布可用结果。** 当前实现按不可变用量版本发布，并可先给出有界临时任务视图。未来项目级提交只有在该项目确实有可打开记录时才能标为“可查看”。
7. **后台跟进。** 可见的概览、任务和来源页面定期检查版本；本机服务同时监听已知来源目录，并以短周期巡检兜底。用户打开任务后，新版本不覆盖正在阅读的位置。

再次打开、页面恢复和运行中新增项目都进入第3—7步，不另设一次性导入状态，也不通过是否点过按钮判断初始化是否完成。

## 项目发现与当前配置

项目目录来自共享 Rust 用量结果的 `facets.directories`。本机 Web 宿主只接受两类项目范围：启动或系统选择器加入的目录，以及当前来源同步已经观察到的项目。浏览器提交任意路径不能扩大读取范围。

直接打开项目配置页时，宿主先对当前来源执行一次增量同步。如果请求路径出现在同步后的项目目录中，就只把该项目加入本次当前配置读取；否则明确拒绝。新项目因此不依赖先打开概览，也不要求重启宿主。配置、优化和 Codex 交接复用同一判断。

“自动导入”只导入派生身份和索引事实，不复制原始日志，不执行项目文件，不写入 Agent 配置。配置文件在用户进入相应项目时按需读取；项目发现本身不触发 Hook、MCP、脚本或 Codex。

## 首次读取界面

首次没有可用结果时，主区域使用固定标题“正在准备历史记录”，显示一句用途说明和当前可确认活动。没有项目证据时显示“正在查找记录位置”；识别后显示数量和稳定列表。项目状态使用“等待整理”“正在整理”“可查看”或明确失败，不显示推测百分比、剩余时间或逐文件日志。

某个项目已有可打开记录后可以先进入任务列表；同时只提示一次“历史仍在读取，用量暂不完整”。后台完成不能把用户跳回概览或关闭正在看的内容。项目同名时显示工作目录；仅有工作目录而无法确认项目归属时按工作目录表达，不把 worktree 自动算作独立项目。

“停止等待”只中止本页请求和跟进，保留已提交结果，后台共享读取可能继续。“继续查看”重新观察现有状态，不清空索引、不无条件启动第二次扫描。单个项目失败不清空其他项目；未来项目级重试只重读失败对象。

## 状态与数据边界

初始化状态由读取周期、来源状态、已提交版本和可用结果共同决定。页面不得从等待时长推断历史规模，也不得把有 `data` 等同于完整。项目级播报需要以下真实事件后才能开放：

- 读取周期身份和来源身份；
- 项目或工作目录身份、显示名与路径；
- 等待、读取、已提交可用或失败状态；
- 可打开的任务或版本引用；
- 覆盖缺口、取消范围和错误码。

事件应从现有扫描过程增量产生，不能为预先计数再次完整解析日志。多个并行项目可以同时处于读取状态；读完一个文件不能证明项目读取完成。屏幕阅读器只在识别数量、活动项目或可用状态变化时合并播报。

## 当前实现与缺口

已经实现：来源发现、活跃和归档历史、事务化增量索引、文件通知与巡检、最后提交恢复、全局首次读取状态、有界临时任务视图、可见页面自动检查、新项目目录自动加入，以及按已观察项目直接读取配置。合成端到端用例覆盖宿主启动前已有项目、宿主启动后新增项目和浏览器伪造路径拒绝。

尚未实现：项目级读取事件、项目级渐进提交、稳定的项目与 worktree 归属、项目级失败展示与单项目重试。缺少这些事件时界面继续显示真实的通用读取阶段，不伪造项目进度。完整首次读取页面不能仅凭现有文案或合成原型标为完成。

## 验证

功能验收至少覆盖：空索引、有旧结果更新、宿主运行中新增项目、直接打开新增项目配置、同名目录、未归属记录、单来源失败、取消后恢复、不可读项目和任意路径注入。测试只使用合成日志和仓库外临时目录，不读取真实对话。
