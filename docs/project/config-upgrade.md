# 概览、任务与配置优化规格

中文 | [English](config-upgrade.en.md)

本页为 2026-10-01 升级的独立公开规格，不代表功能已完成。当前状态见[架构](../development/architecture.md)，验证见 Git 历史中的验证记录。

## 入口与范围

GUI 使用概览、任务、配置、优化四入口，英文为 Overview、Tasks、Configuration、Optimize。CLI 与 Web 并列使用共享 Rust 业务和生成契约；保留 thread 等协议身份。TUI 不恢复；Tauri 是后续宿主。可靠历史工作目录形成可选择的本机项目目录，不要求注册或单独授权；未知浏览器路径仍不能扩大读取范围。

概览同屏显示 Token、USD 标识的标准 API 等价金额、趋势、项目分布、近期任务和优化摘要；单项目显示高用量任务。不因用量增长推断浪费。点击用量或金额进入同一右侧详情，提供构成、时间、模型、项目和相关任务。任务详情默认展开 Token 与金额构成，来源信息按需展开。概览金额两位，正值小于 0.01 显示阈值，详情四位；算法与排序不使用展示舍入值。

日期支持全部，包含日期未知记录并单独标注。配置事件与用量同范围，当前配置内容不随日期改变。检测使用自己的检查时刻，不接受用量页的模型或日期作为闲置窗口。语言沿用 zh/en，切换保留状态，偏好存于本机产品数据目录，启动显式语言优先；不翻译真实任务标题、路径或协议字段。

## 配置事实

仅盘点准确名称 AGENTS.md，包含来源用户根和授权项目中有界发现的文件；不解释加载优先级。项目扫描不进入 .git、node_modules、target、dist 和符号链接目录。缺失、不可读、无效编码、资源上限与完整空内容分开。可靠文件元数据可以单独提供字节数，必须声明来源和状态；旧内容测量标为旧值，不与新元数据合并。

AGENTS.md 的字符数为 Unicode 码点，含空格和换行；Skill 测量完整 SKILL.md，含 front matter，不累加引用文件。description 长度仅来自成功解析字段。MCP 只测可信完整的模型可见定义；没有定义快照时未知，不估连接配置、不执行服务获取定义。

内容 Token 使用全表统一、离线、固定版本的 o200k_base 普通文本基准，记录方法、版本、哈希与适用边界；不是特定未知模型的实际输入，不含聊天包装。超限或失败保持未知，不截断后冒充全文结果。缓存键含内容指纹和方法版本，不保存正文。

使用次数只计明确独立 Skill 调用和 MCP 工具调用/资源读取；读取、加载与连接分开。重复日志去重，失败尝试和独立重试仍计次。AGENTS.md 不统计使用次数；适配器无法观察或覆盖不足时不将未见记录写成零。关联用量取可靠关联轮次内匹配范围的去重计量，多个配置行可能重叠，不相加、不推算独占成本。

## 建议与处理

检测与对象建议分开。同对象格式、description和正文问题合并，格式与规范问题优先。身份含来源、对象和范围；同名不同源不合并。2026-10-02修订采用static-config-v2：AGENTS.md >16,384 B为可调整的产品整理提醒，不诊断宿主加载预算；Skill不再按16KiB文件大小提醒，成功解析后正文独立预估Token ≥5,000才提醒。正文去掉YAML及分隔行，保留精确空白和换行，独立记录方法、分词器版本、哈希与所在配置版本；未知不写零，不用全文相减或字符常数换算。配置表继续测全文。description按Unicode码点：501—1,024为产品提醒，>1,024为规范问题，替代重复的500提醒；人工精简后可转类或关闭。两类边界见[Agent Skills规范](https://agentskills.io/specification)。正文值不是宿主上限、实际消费或预计节省，规范超限也不证明本地加载失败；无法完整解析的扩展不标格式失败。

规则返回默认值、用户覆盖值、固定正文线/规范上限与授权当前配置适用边界。CLI参数或Web提醒值面板只调整产品提醒，值随链接保留并写入处理依据。规范上限不可覆盖。旧缓存无正文测量时未知；旧忽略可读取但不遮蔽新规则。复查另记当前规则，无完整正文估算不标通过。

优化独立显示待处理和处理记录，四种动作类别为修复配置、精简内容、整理扩展、清理空间。每条建议显示依据、检查版本、主动作和复查结果。首期交付静态检查与定位人工编辑、标记待复查、重采集的完整流程；忽略绑定对象、具体问题及范围，独立新问题仍出现。忽略和处理记录独立持久化，不随索引重建丢失。不提供定时暂缓或保留期限。

优化列表采用具体建议、一句价值和一个关键指标。右侧详情依次为建议与处理、相关用量、默认折叠的判断依据；人工处理步骤按需展开。相关记录次数、去重轮次 Token 与 API 估算金额同屏，复用固定配置/用量版本的证据查询，不复制演示数值。关联日期仅筛选记录，不改变静态检查、当前配置或闲置窗口。可定位准确任务轮次并返回原建议、记录、日期、项目/来源、类别、分页、提醒值和原筛选；轮次身份缺失不提供准确跳转。无关联用量未知、历史不可用与覆盖不完整分别说明。

人工标记保留原始安全测量，复查只显示可比较的字节、码点、描述长度与同方法参考Token前后值；旧记录缺基线时未知。不用相关用量、文件变小或阈值差额宣称节省。

Skill/MCP的30×24小时是盘点周期，采用统一截止时刻和包含边界的连续完整覆盖。须当前启用、身份稳定、全部实际适用项目/客户端与事件类别覆盖完整，窗口内无正向证据，才可提醒“未观察到使用”；失败尝试、独立重试也是使用，可靠Skill指令读取可阻止闲置，MCP不能漏掉可识别的资源读取/提示词获取。安装/修改/末次调用时间不证明覆盖。本实现无完整观察适配，保持未支持，不生成闲置建议。

worktree的14×24小时仅为辅助核对；还须关联任务结束、可信确认无关联任务运行、非主目录/锁定/固定保留、完整观察。执行前独立核对未提交/未跟踪/需保留忽略文件、提交可恢复性及宿主注册。覆盖或宿主状态不足不出清理建议。Git默认3个月只针对已消失目录的残留管理信息，不是删除现存目录依据，见[Git worktree](https://git-scm.com/docs/git-worktree)。首期无这些适配，空间能力仍关闭；MCP故障仍需明确连接与原因证据。

配置写入在具备 ChangePlan、前提指纹、准确差异、恢复材料、幂等、逐项回执及恢复冲突验证后才能开放。人工编辑不代表宿主采用；复查失败不标通过，文件变小不声称已节省。只读首期不开放任意写文件、shell 或 dispatch。

## 用户界面与帮助 · 2026-10-03

普通页面说明用户看到了什么、能做什么，以及结果的可靠范围。用量与配置建议默认呈现，不要求先搜索或筛选。研发阶段、评审场景、模拟结果开关和内部执行身份不进入产品导航或普通详情。文件路径、可核对的内容位置、阈值、检查时间和适用条件仍是用户依据；未知、部分覆盖、估算金额和效果未验证须在相关结果旁保留。中文与英文各自自然表达，品牌继续使用“让 AI 工作更高效”与“Make AI work better.”。

统一帮助默认折叠，局部入口直接打开对应主题，关闭后返回原页面或抽屉并恢复焦点。主题限定为：

1. Token 与金额怎么算？
2. 使用次数怎么算？
3. 文本大小和预估 Token 怎么算？
4. 相关用量代表什么？
5. 常见问题。

零值、未知和记录不完整并入使用次数说明。输入包含缓存、输出包含推理，不再次相加；API估算不是订阅账单或额度。文件读取不等于Skill调用，关联轮次总量不是文件独占成本，文本减少不等于实际节省。检测依据用可读的方法、条件和文件位置表达；规则编码、关系身份、原始证据编码和哈希不作为普通页面说明。协议和固定版本身份继续保留，不能为简化展示删掉业务证据。

### 落地顺序与验收

1. 先完善展示：统一五项帮助、局部入口和焦点恢复；用共享语言包映射依据与已知错误。保留路径、位置、条件、未知和恢复动作，普通页面不输出内部身份或未经解释的字段。现有Rust规则与计量不因文案调整而改写。
2. 再核对真实状态：沿用实际查询与已提交结果驱动等待、失败、停止等待和复查。按[首次运行规格](startup-rules.md)补迟到响应、多窗口、断连与持久化故障验收；仅有真实可观测需求时扩展Rust生成契约。文件写入、检测通过、运行生效与实际用量变化分别表达。
3. 最后单独交付执行能力：先完成受限任务、发送内容范围、ChangePlan、预览基线、恢复材料、逐文件回执、幂等续查和冲突处理，再开放模型生成、应用和恢复。关闭、断连或重启后先按持久执行身份查询，不自动重新发送；恢复不能覆盖用户后续编辑，多文件不宣称原子完成。优化任务用量须按真实计量身份与后续日志去重，计入总用量且不被文本减少抵扣。未支持操作按能力返回不可用，不能先显示成功。

展示阶段验收覆盖中英文四页、五项帮助、抽屉返回与键盘焦点、窄屏及未知/部分结果；状态阶段使用真实内核合成故障样本；执行阶段另验发送范围、取消、冲突、部分应用、恢复与计量守恒。静态设计中的计时、预设差异、计量和成功提示不是生产完成条件；私有资料不成为公开构建或测试依赖。

## 验收

1. CLI/Web 同范围、同版本一致；分页不改汇总，跨日轮次完整量与匹配量分开。
2. 同名不同源隔离；重复日志一次、独立重试两次、加载不计调用；未知不为零。
3. 空、缺失、不可读、无效编码、超限和无 MCP 定义各有准确状态；换行变化失效缓存。
4. 一个 Skill 多项命中一个主流程；修复格式后大小问题仍在，description 未知不为零。
5. 忽略不吞新问题；人工编辑后的复查更新当前配置和建议，历史计量保持固定。
6. 配置定位任务轮次再返回恢复对象、筛选与阅读位置；过期明确提示。
7. 中英切换、刷新、重启偏好、弹窗、焦点、长标签及窄屏均验收；原始来源不翻译。
8. 所有记录用合成语料验证；实际执行、其他平台及后续能力不能由原型或构建通过代替验收。
