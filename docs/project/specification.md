# Wombat 用量与对话：首版规格

中文 | [English](specification.en.md)

本页维护首版需求与验收条件，基线日期为 2026-09-30。它不证明全部目标已验收；当前交付与缺口见[实施状态](status.md)，实际结果见[进度记录](progress.md)。迁移前代码盘点已退出当前规格，有长期价值的取舍见[独立计量决策](../decisions/implemented/architecture/2026-09-30-independent-accounting.md)和[快照决策](../decisions/implemented/architecture/2026-09-30-snapshot-storage.md)。

## 范围

| 项目 | 要求 |
|---|---|
| 产品入口 | `wombat` 在 TTY 打开用量/对话，非 TTY 查询用量；明确子命令无需按键模拟 |
| 来源 | 首版只注册 Codex，读取活跃、归档和多根日志；来源协议允许能力不同的后续 Agent |
| 用量 | 日/周/月、日期/时区、模型、强度、项目及对话范围；日期小计、模型分项、完整总计 |
| 对话 | 跨天跨模型列表、原生标题、项目/标题搜索、消耗或最近活动排序 |
| 轮次与记录 | 原位展开、时间/消耗排序、计量分类和安全操作元数据；无正文回放 |
| 多入口 | Rust 业务经生成契约同时交付 Node CLI、JSON 和独立 OpenTUI；未来宿主复用同一受限接口 |
| 平台与语言 | Node.js ≥26.4.0，先验收 macOS arm64；中英展示按[语言契约](../i18n/product.md)，其他平台须独立安装验收 |

不提供额度、体检、配置管理、规则诊断、自动修复、建议、证据包导出、阈值通知、对比、父子任务分析、HTML 报告或 GUI。继承/分叉信息仅用于必要的事实归属与去重。完整当前边界见[支持矩阵](../reference/support-matrix.md)。

## 用户旅程

1. 初次建立本机索引；已有索引先读已提交数据，自动同步后更新主列表。需要固定数据时显式 refresh 保存快照；显式快照不自动刷新。同步失败、未完成和旧结果必须可辨识。
2. 日报默认近7个自然日，周报本周及之前3周，月报本月及之前11个月，均截止今天；手动日期优先。周一起始，按所选时区和每条事件时间分组。对话限定且无日期时使用完整对话范围。
3. 日/模型/强度分项进入相关对话，携带完整筛选。`matchedUsage` 保留来处条件，`threadUsage` 保留整段对话；不能把跨日对话的局部量冒充完整量。
4. 对话展开完整轮次；轮次内部默认时间顺序，消耗排序先列有计量的记录，再按时间列操作。无轮次关联的计量进入“其他记录”，不丢弃或均摊。
5. 轮次份额使用完整对话 Token，步骤份额使用完整轮次 Token。分页、排序及展开状态不改变分母；零分母显示缺值。返回保留筛选、分页、选中及展开。
6. 用量和对话可双向关联；两个主入口分别保留筛选。筛选草稿取消不改变已应用查询，旧快照缺明细时明确不可用。

键鼠、价表、主题与宽度行为的维护入口为[终端指南](../guides/terminal.md)，命令、过滤及错误为[CLI 指南](../guides/cli.md)，此处不另维护帮助副本。

## 数据与呈现约束

- 身份按 Agent、来源实例及上游身份隔离；同名、相同 Token 或近似时间不构成去重证据。项目仅使用精确目录证据。旧稳定身份在可验证时保留。
- 现代响应是独立计量；累计遥测、压缩副本和继承重放不得重复加账。坏行、重放或上下文切换终止不可信继承；当前配置不补历史模型、供应商或强度。
- 工具按同对话中的 call/item 身份连接。缺少明确响应关联时只按实际顺序展示，不用时间接近分摊费用。Skill 仅在明确文件参数指向 `SKILL.md` 时记为文件读取，不宣称承担整轮消耗。
- 非缓存输入、缓存读取、缓存创建、输出互不重叠；推理属于输出。缺失、零、冲突和未知保持区别；原生模型/强度和出处可追溯。
- 标准 API 等价金额与来源 reportedCost、旧政策、订阅实付分开。按单次请求条件计价，逐条未舍入金额在 Rust 汇总，Node 仅格式化；详细规则以[价格参考](../reference/pricing.md)为准。
- 列表金额通常两位、细节四位；小于显示精度的非零值用阈值表达，不变为零。未知显示未知，部分金额带标记；不从显示舍入值重新求和。
- 原生标题缺失不生成用户问题摘要；没有明确轮次编号不冒充原生编号。日期按实际时区和语言格式化，保留来源时间精度，不补造秒数。
- 40/80/120 列采用可读布局，窄屏保留完整金额；品牌不重复，解释在页尾按需展开。原始内容清洗控制字符后仅作数据展示。

## 存储、资源与扩展

来源格式属于适配器，公共模型不依赖 JSONL 或 Codex 私有数据库。能力描述与实际字段可用性分开；只有日汇总的来源不能制造响应或轮次。测试专用异构适配器不代表生产支持。规则与独立真值见[来源验收](../development/adapters.md)。

扫描范围与视图范围分开。完整有效大行必须处理，未完成尾行等待；截断、替换、失败和资源上限有回执。单次读取固定各文件边界，不宣称多文件源头原子一致。默认不保存消息、模型正文、完整命令参数或工具输出；来源数据不能触发命令。

显式 v3 快照使用不可变 generation、manifest、分片及校验，取消或失败不发布半份快照；v1/v2 窄只读兼容保留原身份、金额政策及缺失语义，不删除用户原始文件或恢复材料。后续实时索引与按需服务已部分交付，完整目标仍以[实时架构提案](../decisions/proposed/architecture/2026-09-30-live-usage.md)为准；它不改变显式快照责任。

常规快照列表/展开 p95 ≤300ms、冷查询 ≤1s 是原始目标，不能当作实测结果。报告须包含固定语料、release 构建、缓存状态、进程启动、I/O、序列化、渲染与峰值内存。性能瓶颈先通过读取与投影证据判断，再选择索引；不要把解析局部加速宣传成整条链路改善。

## 验收与交付

| 类别 | 必须验证 |
|---|---|
| 来源扩展 | 身份隔离、不同缓存语义、无轮次能力、未知供应商、失败隔离；公共查询无需增加来源专用分支 |
| 账本 | A01–A12 独立真值，新旧格式、复制/继承、累计回退、历史上下文、冲突与未知；不依赖 ccusage 对账 |
| 范围和守恒 | 时区/夏令时、跨日/月/年/模型/强度、归档与多根、未知日期、未归轮计量；完整账本与各层总量一致 |
| 金额 | 精确/别名/供应商匹配、阈值下/等/上、缓存类别、零与未知、政策隔离、小额精度、价表升级与旧结果固定 |
| 查询 | 全范围排序后分页、稳定分母、双向关联、固定版本、取消/忙/部分失败、损坏与缺明细 |
| 终端 | 40/80/120 列，中英切换、长模型名/原生标题、键鼠、筛选、展开、返回、缩放、取消及退出恢复 |
| 安全与安装 | 完整大行、尾行与截断、白名单正文隔离、无任意执行、干净构建/安装、执行权限与第三方通知、原始来源不写入 |

按[开发流程](../development/workflow.md)选择验证：跨语言测试前 build，检查生成契约和模块边界；依赖变化同步许可证；发行检查包清单和干净安装。TUI 与无交互接口合起来才算同一能力交付，浏览器演示不能替代真实终端。只有实际完成的证据进入[进度记录](progress.md)，其他平台和真人任务效果另行验收。
