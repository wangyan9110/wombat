# 五入口与优化闭环规格

中文 | [English](optimization-lifecycle.en.md)

2026-10-03 确认的新版范围：Wombat 查看、确定性检查、组织建议、发送到本机 Codex 和复查；用户在 Codex 审阅、执行、决定停用或清理及恢复。Wombat 不提供另一套方案生成、应用审批、执行进度或批次管理。实现状态见[实施状态](status.md)，不能以原型或历史测试数代替产品验收。

## 页面与共享事实

概览、任务、指令、扩展、优化共用来源、项目、日期和用量账本。概览同时展示 Token、API 估算金额、账户额度、趋势、分布及最近任务。指令按用户、项目和子目录形成 AGENTS.md 树；扩展平铺 Skills、MCP、Hooks。两页分别保留搜索、排序和建议筛选。

任务总用量、当前筛选和当前轮次分开。最近轮次按可靠记录时间定位，不能取最大编号。页面不回放完整对话正文。跨页返回恢复范围、筛选、轮次、列表和查看位置；刷新、语言切换与迟到响应不能覆盖新选择。日期包含首尾两天，全部包含日期未知记录；当前文件和账户额度不受历史日期影响。

当前配置身份、历史工作目录和额外目录来源分别保存。可靠历史项目可在用户切换后直接读取当前配置，但不证明历史加载；共享文件只采集一次，未归属任务不按路径相似度猜项目。Token 总量为输入加输出，缓存和推理分别是子项；金额按原始精度逐记录计价。未计价 Token 保留，未知金额不补零。关联用量按明确计量身份取并集，不分摊对象独占成本或预测节省。

## 规则与资源

AGENTS.md 完整 UTF-8 文本 >16,384 B 提醒，等于不触发；缺失为事实，可选创建。Skill 正文排除 YAML，有效解析及明确方法下 ≥5,000 预估 Token 提醒；description 501—1,024 Unicode 码点提醒，>1,024 在规范适用时单独报错。无效 YAML 不产生确定正文结论。

完整块只比较原文和可靠完整边界，作用链或上下文须明确。同请求重复注入要求真实请求、上下文、代次、来源版本和实际位置；去除重放，不混合父子任务或压缩代次。副本差异要求明确关系、双方版本、变换及方向，用户定制不能被自动覆盖。Hook 引用来自可信有效启用注册表，不执行脚本；动态路径和权限拒绝不判缺失。

Skill/MCP 闲置要求稳定身份、连续启用、至少30天完整可观测覆盖且无使用，包括失败尝试。Worktree、缓存和临时资源需要至少14天完整观察及无活动、任务结束、无运行任务且非保护；缓存另须可信归属及可再生成，Worktree 另须修改、提交和恢复材料。目录时间和界面筛选内零次不替代这些证据；移入可恢复区不等于释放空间。

连续快速检查的版本化初始参数为：同一运行任务连续至少5次、间隔不超过2秒、无新输出、无输入或及时响应要求。整体还需至少5个可分析任务、3个命中任务、2个命中日期，并在观察终点前最近7天有命中。必要保活、交互、长等待及证据缺口排除；无可修改位置时只展示依据。

使用次数来自 Skill 明确调用、MCP 工具/资源/提示词及可靠 Hook 运行事件。读取 SKILL.md、列出、加载或连接不算调用；独立失败与重试各计一次，稳定事件重放去重。完整覆盖无事件才是0；不完整覆盖有事件为已观察次数，无依据为未知。AGENTS.md 只展示读取。

## 发送与处理

单项绑定当前建议、对象与项目。关闭未发送批量选择即结束；再次单项不复用旧选择。批量候选覆盖当前项目全部符合条件建议，不受展示页或类型限制；默认选择当前仍待处理的项；不遍历历史发送，也不保存任务关联来排除重复。共享对象去重，同文件规则合并，跨项目保留各自工作目录。

发送只包含必要目标、工作目录、规则、依据及版本、处理方向、保留条件和访问限制，不默认交接完整历史或私人文件。发送前提示处理任务产生 Token 用量；全选不授予任意删除权限。

发送时核对Codex是否接受请求，不在Wombat维护执行回执；是否解决由重新检测判断。发送期间抑制重复点击，不维护跨进程锁或历史查重。明确失败保留建议；发送结果不确定先在Codex核对，用户可重新确认后手动重发，不自动重发。采用受支持的本机路径，不能把开发会话协作工具或固定样例当作产品接口。关闭 Wombat 不取消已发送任务；审阅、执行及恢复由 Codex 管理。

## 决定与复查

检查事实与用户决定独立，接受交接请求不改变检查结果或用户决定。保留或不适用记录对应问题实例、原因及真实时间；新问题实例单独核对，索引重建不清除决定。重新显示建议只恢复展示，不恢复文件。刷新不重建处理时间，已发送不等于已解决。

单项和全局复查共用规则，只检查当前授权范围，不启动模型。按依赖逐规则执行：历史缺口不阻止可读文件的大小、格式或引用检查。问题通过移入处理记录，仍存在保留待处理，无法检查保留原建议和上次结果；文件消失不自动通过。复查不撤销用户决定。

静态结果与自然后续采用分开：没有新记录、版本未知、确认采用或同类问题再现。不为验证收益额外运行模型。实际优化用量按可靠计量身份与历史去重，未知不补零；同范围同方法的文本变化不是因果收益。

## 启动、账户与验收

外壳先出现，真实事件说明查找、读取、建立和保存索引，无可靠分母不显示百分比。部分任务先可查看，完整汇总未完成明确标部分，完成后保留已打开任务。停止等待仅停止页面等待，不宣称共享扫描取消。找不到来源、无记录、无计量和筛选无匹配分开；授权静态文件可读时继续检查。

账户身份、额度、账户摘要独立读取并降级，登录和凭据由 Codex 管理。实际窗口周期、名称、单位和重置时间不固定五小时或七天；未知、陈旧或已过重置不恢复满额。其他模型桶不阻止当前任务，只有新鲜且明确适用的限制影响请求。本机用量和账户额度不换算或相加。

语言仅一个全局入口，动态消息完整双语，英文单位按数量变化。窗口关闭、来源权限、存储不足、失联和未知格式保留明确状态与可用旧结果。未发布首版只维护当前格式，不实现旧页面、协议、索引或数据库迁移；未知格式拒绝并保留原数据。

| 启动与账户 | 分区可用、旧结果、真实进度、任意额度窗口及独立降级 |

全部工作包均属于本次范围；实际产品旅程逐项验证，构建或原型检查不能替代验收。
