## Web 首轮交付 · 2026-10-01

`ui/`、`web/` 与 HTTP 客户端接入新版用量、对话、轮次、来源和价表页面，CLI 可启动本机 Web。新分组与匹配排序由共享 Rust 契约提供。桌面仍采用已选 Tauri 2；项目注册、实际执行及其他平台浏览器验收待后续。页面范围与差异见[前端说明](../../ui/README.md)，验证见[进度](progress.md)。

## 配置测量与人工处理 · 2026-10-02

概览、任务、配置、优化四入口已接入统一用量详情、日期全部、配置全文 Token/码点/字节测量、Skill 静态检查、对象级建议和完整人工复查；忽略及处理记录独立持久化，语言偏好跨服务重启保留。Web/CLI 使用同一生成契约。范围见[升级规格](config-upgrade.md)和[配置契约](../development/contracts.md)。

首期交付不代表条件性后续能力完成：连续覆盖闲置判断、MCP 故障、空间资源适配、配置执行与恢复仍关闭；项目注册、加载优先级、显式 Skill 调用与 MCP 资源事件适配、历史配置版本、持久复合版本、增量证据索引、协作取消和 Tauri 仍待后续。实际浏览器与性能证据见[进度](progress.md)。
