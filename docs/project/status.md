## Web 首轮交付 · 2026-10-01

`ui/`、`web/` 与 HTTP 客户端接入新版用量、对话、轮次、来源和价表页面，CLI 可启动本机 Web。新分组与匹配排序由共享 Rust 契约提供。桌面仍采用已选 Tauri 2；项目注册、优化规则及其他平台浏览器验收待后续。页面范围与差异见[前端说明](../../ui/README.md)，验证见[进度](progress.md)。

## 四入口与只读配置 · 2026-10-01

已接入配置清单、类型/证据筛选、分页、配置与回合的双向关联，Web和CLI复用Rust配置v1契约。优化入口目前提供只读配置核查。完整方案仍未全部交付：稳定项目注册、配置优先级、内容Token估算、增量证据索引、持久复合版本、协作取消、自动建议、配置写入和Tauri待后续。当前边界见[配置契约](../development/contracts.md)。
