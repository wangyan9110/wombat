## Web 首轮交付 · 2026-10-01

`ui/`、`web/` 与 HTTP 客户端接入新版用量、对话、轮次、来源和价表页面，CLI 可启动本机 Web。新分组与匹配排序由共享 Rust 契约提供。桌面仍采用已选 Tauri 2；项目注册、优化规则、TUI 删除及其他平台浏览器验收待后续。页面范围与差异见[前端说明](../../ui/README.md)，验证见[进度](progress.md)。
