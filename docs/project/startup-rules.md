# 首次运行与确定性规则升级规格

中文 | [English](startup-rules.en.md)

2026-10-02。状态：A1—A4已实施，A5已有受控故障及本机验收但规模/平台边界未完成；B0/B1/B2/B4已交付确定性分支，B3仅有不可用能力边界。它补充[首版规格](specification.md)与[配置升级](config-upgrade.md)，不替代[支持矩阵](../reference/support-matrix.md)和[实施状态](status.md)。公开构建、测试和贡献不依赖外部原型或私有资料。

## 产品边界

保留概览、任务、配置、优化四入口，CLI 与本机 Web 消费同一 Rust 业务与生成契约。Token 与 API 估算金额同屏，缺失、零、未知和未计价分开；默认读取无需登录、API Key、模型下载或模型调用。来源根、历史工作目录与当前配置授权根分别处理，历史目录不自动获得当前文件访问权。

首次读取包括活跃和归档历史的整理与派生索引建立。默认显示近30天不代表仅扫描近30天。不强制注册项目，不扫描全盘，不执行 MCP、Hook 或生成脚本，不改写来源配置。当前 Web 更换授权目录须重启宿主；目录选择器、Tauri 与自动执行均属后续交付。

| 新确定性规则 | 完整读取、字节/码点/参考Token、内容哈希与路径边界 | 块解析、适用链、显式副本关系和宿主Hook适配；现已提供完整块、用户声明链和identity-v1副本；Hook未有有效注册适配 |
| 注入与执行 | 文件读取及MCP调用事实 | 缺实际片段/上下文、执行与恢复证据；继续不可用 |

## A阶段：启动与异常状态

页面外壳 → 本机连接 → 整理历史并提交索引 → 基础用量可看 → 近期任务、配置建议各自完成。只显示实际可观测状态；无可信总量时不显示百分比或剩余时间。约1秒明确进行中、约10秒补充较久说明是交互建议，不是性能保证。

状态应区分：首次无结果、正在同步、已有结果更新中、更新失败但旧结果可用、来源空、任务无计量、筛选无匹配、来源部分失败、价表未知/离线、当前请求取消、连接失效、版本过期、配置不可读、迁移与存储失败。原始错误可以按需展开，不能以通用失败替代正常整理，也不能以零掩盖覆盖缺口。

取消文案为“取消等待”。停止本页请求与跟进，保留已提交索引；后台共享扫描可能继续，不承诺全局停止或撤销。首次取消且从未成功提交结果时明确尚无结果。重新进入复用已有工作，多窗口不能互相取消。

已有结果和新查询严格按来源、范围、日期、模型及版本绑定。旧范围不能作为新范围结果；迟到响应丢弃。阅读任务/明细保留原版本并提示可更新；旧版本失效恢复查询条件，不承诺永久恢复版本。相对日期意图与手动日期分别存储，前者跨日重新计算，后者保持固定。

基础计价失败不影响Token读取。Web后台补价须沿用Rust缺价资格、限流和版本发布，避免多窗口重复下载；宿主退出停止其联网任务，不中止其他入口共享扫描。取消本页等待不冒充共享任务已终止。已有固定快照不重算，补价产生新版本，由阅读状态决定何时应用。下载失败保留未知金额和可重试状态，不伪造零费用。

需要进度接口时，先证明作业身份、阶段、开始时间、已提交版本、可用结果、覆盖和取消范围可观测，再从Rust生成窄DTO。页面elapsed与核心elapsed不同；没有统计能力的计数/总数字段缺失。不得为原型一次引入通用dispatch或空洞的任务框架。

旧索引迁移是升级路径，不是全新安装必做步骤。失败不清除旧快照、忽略、基线和回执；存储不足须明确失败，不能回执已保存。当前没有只读降级数据库、通用重建或清理操作，新增前需独立设计，不能用原型按钮替代。

### A开发拆分

| 工作项 | 责任与依赖 | 完成条件 |
|---|---|---|
| A1 页面外壳与偏好 | UI、共享语言；不依赖新内核能力 | 偏好延迟/失败时外壳可见；显式语言及用户切换优先；无闪回和草稿丢失 |
| A2 进行中与旧结果 | UI协调器、现有live freshness；先做状态映射 | 首次pending自动跟进、取消停止本页；已有旧结果可读、更新状态准确；范围/版本隔离 |
| A3 后台补价 | Node宿主生命周期、Rust既有限流；必要时扩展生成响应 | 延迟下载不阻挡用量；多入口不重复请求；退出清理；新旧版本与未知金额准确 |
| A4 覆盖、偏好与恢复 | Rust明确错误、UI分区状态、日期意图 | 空/无计量/部分失败/异常配置独立表达；相对日期跨日，手动日期固定；未保存不成功 |
| A5 可观测性与升级验收 | 核心状态仅按真实需要扩展；故障样本与浏览器测量 | 连续作业/多窗口/迁移失败/磁盘满有证据；不增加虚假阶段或ETA |

## B阶段：确定性规则与前置证据

规则标识是候选名，注册时与当前规则版本对齐。文件相同、共同授权根、父子目录或相同任务名均不能独立证明共同加载链。完整静态内容事实与实际注入事实分别维护。

| 分支 | 必要事实 | 未知与排除 | 动作及复查 |
|---|---|---|---|
| `CFG-DUP-01/content` | 完整Markdown段落/列表、原文字节区间、来源/版本、可靠共同适用链及条件 | 哈希命中后原文核对；保留中文、大小写、标点、内部空白和行尾；标题、代码例子、引用例子不独立算块；作用链未知只盘点静态事实 | 展示各位置和条件，人工核对合并或保留；完整重读全部关联版本后复查 |
| `CFG-DUP-01/injection` | 同一实际request/context、同来源版本、两个明确纳入位置 | 读取不等于注入；事件重放去重，真实第二位置保留；父子/新request/压缩代次分开 | 修正入口后，下一次可比真实上下文核对；无适配保持不可用 |
| `CFG-SYNC-01` | 用户/宿主明确的source/copy/方向与版本化变换声明、双方当前版本 | 不从同名/相似度猜关系；无法识别变换保持未知；来源不自动正确，插件副本走宿主管理 | 展示声明与双边差异，用户选择方向/保留定制；按同声明变换复查 |
| `FILE-REF-01/hook-target` | 受支持宿主、有效启用Hook、确定解释器/脚本参数与路径基址、可信不存在证据 | 动态shell/变量、权限不足、未知宿主/基址或软链边界不判缺失；不执行Hook | 定位注册与目标，人工改路径或明确停用；重查存在及启用状态 |
| 自动注入盘点 | 明确来源、事件/上下文/范围和实际取得内容 | 本身不是缺陷，不从体量或次数预测节省；范围与能力不足公开 | 尺寸、参考Token、可识别次数独立展示；当前缺片段适配，不开放假数据 |

共同适用链、副本声明入口/格式、首个Hook宿主与支持命令子集是B阶段的输入规格，当前声明格式已交付，Hook宿主仍未确认。声明只表达用户意图，不证明宿主加载；Hook须先有适配才能开放相关建议；不能降低门槛为“同一项目就判重复”。

按对象合并体量和重复分支，保留各分支证据、规则版本和条件；不得将重复区间多次相加。忽略指纹包含所有关联文件版本、作用链/声明/宿主证据及解析策略，另一端变化也须重新判断。全部读取及适用关系可比才复查通过，删除/不可读/关系未知不是解决。

文本减少量只说明可比内容变化；事件次数、相关轮次用量及未来执行用量分别保存，稳定计量身份去重，不分摊对象独占费用，不汇总为浪费/净节省。可靠Skill调用、MCP资源、实际注入、闲置观察和Hook执行健康不由本批静态规则补造。

### B数据结构与开发拆分

目标为按内容版本与解析策略缓存；当前每次配置采集重新解析，不落盘保存正文或块缓存。原文区间用于核对，不按每个位置复制正文。候选按长度和二进制哈希分组，命中再比原文；相同内容输出一组位置列表，避免两两配对。嵌套区间排序后去重，完整单元不足时公开resourceLimited。期望解析/哈希随总字节与块数增长，区间排序为O(B log B)，碰撞复核另外计量；不会静默丢弃有效大行。

源码位置、来源实例、文件版本、对象身份和上下文身份各司其职。后续增量更新目标为仅替换变化文件的块位置，派生数据和用户决定分开。解析器采用成熟库并锁版本/许可证；现有YAML解析/Token估算不等于已有Markdown完整块解析。

| 工作项 | 依赖与交付 | 验收重点 |
|---|---|---|
| B0 证据输入 | 明确适用链、副本声明和Hook宿主/路径规范；Rust类型与共享生成契约 | 未声明/未知宿主不可伪造有效关系；授权不扩散；版本与来源隔离 |
| B1 完整块与重复 | B0适用链、成熟Markdown位置解析、缓存和有界分组 | 中文/完整列表/条件/排除/强制哈希碰撞/重叠/巨大重复组；CLI与HTTP相同位置 |
| B2 声明副本 | B0声明；首先支持已定义的确定变换 | 双边修改、方向、插件归属、另一端变化、声明变化、无法识别变换和复查不足 |
| B3 Hook引用 | B0宿主；首先支持确定解释器与静态脚本参数 | 启用/禁用、路径基址、引号/空格、缺失/权限/动态表达式/软链；任何检查不执行脚本 |
| B4 建议与人工闭环 | B1—B3共享证据、指纹、分页、原有处理记录 | 按对象合并、中英同口径、关联用量守恒、忽略失效、用户基线保留、删除不假通过 |

## 验收数据与阶段完成标准

新增验收在隔离合成目录执行，原型检查和历史测试数不算本批通过。记录构建哈希、平台、数据和当前结果；已有样本可以复用，但须重新确认适用。下列编号为本规格验收编号。

| 编号 | 数据/操作 | 关键断言 |
|---|---|---|
| B01—B05 | 新数据目录；活跃+归档、仅旧历史、无日志、只有任务无计量、大历史取消 | 正常可读、归档不重账；日期空可查看全部；未知非零；pending与无记录不同，首次取消无旧结果 |
| B06—B10 | 错误/拒绝目录、未知格式、离线缺价、多根单源失败、组合筛选空 | 范围/能力/原因准确；Token不被补价阻断；健康来源与旧贡献准确；清筛选不改授权 |
| B11—B16 | 时区午夜/未知日期、多模型缺轮次、同名跨源与归档、未授权或删除配置、超限/编码、读取/MCP失败 | 分层守恒、身份和日期不猜；当前未知不解释历史；读取不当调用，失败尝试保留 |
| B17—B19 | 导入旧历史、无建议/全部忽略/检测不可用、人工修改后删除/方法变化 | 不造连续闲置；三类状态分开；用户回执/基线保留，证据不足不解决 |
| B20—B23 | 切范围迟到响应、多窗口一方取消、重启/失效版本、跨日偏好与手动日期 | 范围/版本隔离，不误取消；新链接恢复；相对日期滚动/固定日期不变；偏好失败不阻塞 |
| B24—B26 | 迁移坏记录/写满、两语390px与键盘、同版本CLI/HTTP | 存储失败不成功、不删用户状态；操作与身份可达；数值/次数/建议一致 |
| R01—R04 | 精确块/链、明确副本、Hook静态与动态、注入重放/真实位置/父子 | 分别满足必要事实；未知分支不造建议；缺适配不开放；规则变化/多对象复查独立 |

A阶段覆盖B01—B26的适用生命周期；B阶段另完成R01—R04中的确定性分支。安装/其他平台、真实来源、百万级、24小时常驻和迁移资源不能由合成页面或本机测试代替。C阶段执行的认证/隔离/差异/冲突/部分应用/恢复/原生日志计量去重，D阶段连续闲置/空间与桌面另行验收，本页不将其标完成。

## 性能与后续范围

分别测启动URL就绪、页面外壳、首个有效用量及各分区完成；记录release、语料、缓存、平台，以及Rust/Node/浏览器内存和临时/稳定磁盘。既有[大历史基准](../benchmarks/compact-live-index-2026-10-02.json)约4.49秒与[配置基准](../benchmarks/config-measurement-thresholds-2026-10-02.json)约0.37秒为不同构建/样本的CLI结果，不相加为GUI耗时或用户ETA。迁移耗时、首屏和大规模尚待测量。

当前核心仍随历史规模持有安全事实；紧凑索引和缓存预算不是全进程硬上限。B阶段基准须包括解析、范围核对、索引持久化与查询，单独报告巨大重复组和碰撞复核，不能拿编码布局样本宣传整条产品节省。

实际注入和Codex执行保留为C阶段。查看/静态检测不依赖执行引擎；执行前才检查就绪。限定内容、隔离生成、差异审阅、基线校验、逐项回执、同执行ID续查与冲突恢复须先完成；没有运行时证据不安装/登录、不借桌面私有接口、不开放自动写入。D阶段按宿主适配交付连续观察、受保护空间处理和Tauri，不能由本批规则顺带认定完成。

## 当前声明与资源边界

跨文件检查只读取已授权项目中已有的 `.wombat/analysis.json`，格式由[生成Schema](../schemas/analysis-declaration-v1.schema.json)定义。产品不自动创建声明、不从同名/目录关系推断共同加载，不扩展清单外文件。示例：

```json
{"version":1,"chains":[{"id":"joint","files":["AGENTS.md","child/AGENTS.md"]}],"copies":[{"id":"copy","source":"AGENTS.md","copy":"copy/AGENTS.md","transform":"identity-v1"}]}
```

路径只允许授权根内的相对普通分量；双方须已在完整当前清单内。chains仅支持Rule；Skill正文可作同文件检查，YAML不参与。identity-v1比较完整原文字节，包括行尾，不代表原件必然正确。声明变化、另一端变化、条件或相对引用基址不同均须重新核对；不支持的变换与Hook宿主明确未知。

单文件1MiB、单轮8MiB、32,768块、每组4,096位置、每对象256分支、输出证据2MiB；声明64KiB、256关系、每链2—64路径。超限公开缺口，不能作为完整复查通过。标题条件与原文字典共享，碰撞后仍比较原文字节；正文只在有界本轮内驻留。规则版本static-config-v4，用户记录独立保留。细节与理由见[决定](../decisions/implemented/architecture/2026-10-02-startup-static-rules.md)。

当前有首次等待/取消、可读旧结果、异步偏好、相对日期和Web宿主后台补价；来源页公开启动授权根和macOS/POSIX重启材料，复制不执行。INDEX_MIGRATION_FAILED、INDEX_UNSUPPORTED_VERSION、STORAGE_FULL及STORAGE_UNAVAILABLE明确失败；旧记录不清空，没有自动重建/只读降级入口。SQLite受控写满、迁移坏记录与同服务恢复有证据，不代表真实磁盘耗尽或所有权限故障验收。
