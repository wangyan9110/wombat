# Wombat 路线图

中文 | [English](roadmap.en.md)

本页只列后续方向，不承诺发行时间。独立 Codex 计量、官方价格、两入口与当前格式快照已形成基线；需求见[首版规格](specification.md)，交付与缺口见[实施状态](status.md)，证据见[进度](progress.md)。

1. 先按[界面与配置升级规格](config-upgrade.md)完善用户视角、按需帮助和检测依据，再按[首次运行与规则升级规格](startup-rules.md)补A5规模/平台验收、B3有效Hook注册适配与增量块缓存；保留实际注入及执行的证据门槛。
2. 推进[自动更新架构提案](../decisions/proposed/architecture/2026-09-30-live-usage.md)的剩余部分：持久 MVCC、按依赖局部归并、数据库聚合、百万级性能及 24 小时验收。增量游标、SQLite 事务、按需服务和自动查询已接入，提案不能整体标完成。
3. 用固定语料继续验证来源版本、正确性与全链路资源消耗；真人任务试用单独记录，性能目标以实测确认。
4. 为首次 GitHub Release 完成其余四个平台的托管干净安装、许可证与公开资料检查，并核实公开仓库的分支保护、私密漏洞报告及一键安装地址。
5. 按真实需求接入下一 Agent 或桌面宿主；先复用共享适配协议和受限客户端，再扩展产品入口。

中英 CLI/Web 已交付，来源原文和未知内核诊断保留原语言。账户及本机Codex交接按[闭环规格](optimization-lifecycle.md)追加实施；旧环境管理、诊断、自动应用/恢复和报告不能以历史实现视为当前能力或承诺恢复。

## 当前迁移顺序

CLI+Web 已基于共享 Rust 契约落地，TUI 产品代码已移除。继续按新版产品方案完善共享前端与已选 Tauri 2 宿主。
