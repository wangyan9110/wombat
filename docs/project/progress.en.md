## Sync request coalescing fix · 2026-10-04

Fixed repeated queries for the same source filling the 32-slot queue during slow synchronization. Queries share pending or running work; read timeouts do not add duplicate jobs. Pending work can be upgraded to full verification, while verification requested during an ordinary sync shares one subsequent job. Background checks use the same completion state to avoid racing new requests. Failed enqueue attempts no longer leave a false syncing state; a full queue and a disconnected receiver return UPDATE_BUSY and CORE_UNAVAILABLE respectively.
