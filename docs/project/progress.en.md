## Automatic checks for missing prices · 2026-09-30

Live CLI/TUI queries fetch the fixed official catalog when Rust identifies valid nonzero OpenAI usage with missing rates. Missing model names, provider mismatches, conflicting tokens, and unknown request conditions alone are excluded. Persistent Rust state, file locks, and 60-second leases coalesce cross-process requests. Failures cool down for 15 minutes and successful checks for 24 hours; the host caches receipts. Automatic downloads time out after 5 seconds. Failures preserve usage/catalog data with a separate priceUpdate state; success repeats the original filtered query once. Cached queries, fixed snapshots, and WOMBAT_AUTO_PRICES=0 do not trigger automatic networking. Manual updates can retry immediately. Semantics are in [pricing](../reference/pricing.en.md) and the [decision](../decisions/implemented/architecture/2026-09-30-automatic-prices.en.md).

Rust fmt/clippy, types/import boundaries, generated contracts, and repository checks passed. Ordinary regression cases explicitly disable automatic networking; dedicated cases enable controlled downloads and do not depend on the live official page.
