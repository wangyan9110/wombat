# Wombat 路线图

当前收敛为用量与对话两入口，先完成[首版方案](usage-threads-v1.md)的 CLI/TUI 与共享查询。实际完成状态见[实施跟踪](implementation-tracker.md)，验证见[进度](progress.md)。

1. 独立 Codex 计量、官方价格、轮次与操作明细。
2. 两入口完整路径、机器接口、旧快照只读兼容、依赖与旧功能清理。
3. 优先推进[快速自动更新架构提案](decisions/proposed/architecture/2026-09-30-live-usage.md)：Rust增量采集、派生索引、按需共享服务与订阅通知；已接入增量游标、SQLite事务、按需服务和自动查询；持久MVCC、按依赖局部归并、百万级性能及24小时验收仍待交付。
4. 用固定语料继续验证来源版本、正确性、全链路性能和用户体验。
5. 按真实需求接入下一 Agent；共享适配协议已作为设计边界，不提前增加产品入口。

其他平台、英文完整界面和桌面宿主仍为后续候选；自动更新的目标性能需实施后单独验证。旧环境管理、额度、诊断、修复、观察和报告不属于首版，不能以历史实现视为当前产品能力。
