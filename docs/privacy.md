# 隐私与本地数据

Wombat 默认离线、无需 API Key，只读本地 Codex rollout 日志和标题索引。基础刷新不联网拉价格，不修改 Codex 日志、配置、登录和安装。

派生快照保留 Token 分类、价格依据、来源/对话/轮次身份、模型与推理强度、时间、项目、原生标题，以及安全操作字段（工具名称、文件路径、退出码、耗时、MCP server/tool）。原始用户消息、模型正文、完整命令参数、工具输出不进入快照或 Node 响应。模型、标题、路径和名称仍可能包含敏感信息，不应随意外发。

产品数据位于系统应用数据目录，可用 WOMBAT_DATA_HOME 指定。文件使用私有权限和原子替换；快照不是加密保险库。本版没有上传、全文回放、证据导出或任意执行能力。

来源目录会持续变化，单次刷新固定每个文件观察到的边界；部分失败、未完成尾行和无法确认的关联保留状态。工具调用没有独占Token时不伪造费用。官方 API 等价金额不代表订阅账单。

测试与公开仓库只使用合成语料。真实来源自测输出必须在仓库外，未经审查的 raw、真实对话与密钥不得写入测试或公开资料。历史用户决定、身份登记和恢复材料不随废弃功能清理删除。
