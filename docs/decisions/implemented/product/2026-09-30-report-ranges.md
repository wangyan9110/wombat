# 决策记录：报表默认日期随粒度变化

更新（2026-10-01）：[TUI 移除](../architecture/2026-10-01-remove-tui.md)后，下述终端专属行为仅为历史。当前 Web 范围与导航以[前端契约](../../../../ui/README.md)为准，共享内核查询仍为数据口径依据。

## 问题

近7天原先应用于全部分组，终端又将响应日期写回请求，导致周报和月报仅汇总最近一周。

## 决定

共享内核选择日报近30天、周报本月及之前5个月、月报本月及之前11个月，均截止当前时区的今天。显式日期、完整对话和未知日期筛选优先。终端保留隐式请求日期，仅用响应日期展示范围；筛选“随报表”恢复自动范围，TUI切换周期也恢复该范围，保留模型和项目。

## 考虑过的方案

只看本周/本月不便比较上期，默认全部历史扩大日常查询范围，因此采用有限的多个周期。仅在界面计算会与CLI口径不同，故日期算法由内核负责。

## 影响与验证

改变日/周/月无日期请求的默认范围，不改变采集或快照，无新增协议字段。固定日期边界、CLI合成账本、原生交互和PTY切换覆盖验证，执行结果见[进度](../../../project/progress.md)。
