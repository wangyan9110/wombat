# 决策记录：首次运行与有界静态规则

中文 | [English](2026-10-02-startup-static-rules.en.md)

Status: implemented

## 问题

首次页面等待偏好或联网价格时缺少可用入口；正常索引等待曾显示为失败。静态重复若从父子目录或相似文本推断加载，缺少可信依据；逐位置复制条件及两两配对还可能放大资源。

## 决定

UI先渲染外壳，偏好异步恢复且用户选择优先。等待时钟属于页面；旧结果按范围绑定，来源更新失败仍允许同范围下钻。Web注入无自动补价装饰的Node客户端，由宿主持有单一有界联网任务；资格、跨进程限流、计价及固定版本仍由Rust管理。取消页面等待不取消其他用户共享扫描；宿主关闭只取消其联网工作。

Rust使用锁定pulldown-cmark完整块与原始UTF-8位置。哈希选候选，原文字节复核；完整段落/最大列表、共享标题条件和分组位置避免复制长标题或两两配对。正文、字典及标题仅驻留本轮，输出安全版本/位置元数据。采用[契约](../../../development/contracts.md)的字节、块、位置、分支及元数据预算，超限公开缺口且不能复查通过；没有新增持久正文缓存或全进程硬内存保证。

已有授权项目的analysis.json表达用户声明共同适用及identity-v1副本方向；不证明实际宿主加载，不从同名推断，不读取清单外路径。副本比较全字节，来源不自动正确；指纹含双边版本与声明。缺失、权限、资源或关系不足不能作为解决。用户处理记录独立存储，旧记录可读，重建索引不清理它们。

Hook 注册观察及静态命令子集由后续[注册观察决定](2026-10-04-hook-registry-observation.md)扩展，不证明实际注入或运行健康。存储失败和未知索引格式明确报错并保留原记录，不自动清空或重建。

## 考虑过的方案

阻塞偏好和价表让首个结果依赖非必要工作；使用目录或文本相似度猜加载关系会混淆用户意图与宿主事实。当前选择显式声明和原文核对；没有采用字符片段重复率、执行Hook验证或实际模型调用。持久增量块缓存需要独立版本、失效和清理设计，留待实际采集成本验证后交付。

## 影响与验证

Markdown依赖锁定并保留许可证，证据约束见[复查完整性决策](2026-10-02-rule-review-integrity.md)；公开DTO由Rust生成。合成真值覆盖中文/CRLF、完整单元、示例排除、标题条件、碰撞、Skill正文位置、巨大组上限、关联版本/声明变化和复查不足；CLI/HTTP同版本一致。Web覆盖基础结果不等价表、多页共享和生命周期；存储覆盖SQLite受控写满及坏旧索引恢复。

本机测量与浏览器范围见 Git 历史中的验证记录。当前不证明真实磁盘耗尽、所有权限情况、其他平台、百万级、24小时常驻或实际注入/Hook健康；局部解析时间不宣传为整条首次启动耗时。
