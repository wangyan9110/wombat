# 决策记录：MCP 调用身份、资源读取与分叉重放

中文 | [English](2026-10-04-mcp-runtime-evidence.en.md)

Status: implemented

## 问题

只读取通用工具记录会漏掉原生 MCP 完成结果；从 `mcp__` 前缀拆服务名既可能误关联，也不能识别资源读取。分叉复制的历史事件与独立重试需要不同处理，配置使用次数不得因此增减账本。

## 决定

来源适配器读取原生 MCP 开始/完成事件及持久 `McpToolCall` 项，只保留身份、类型、结果和耗时。原生服务身份优先于工具名前缀；明确身份冲突后不再关联配置。资源读取由准确的内置请求名、有效服务/URI 参数和调用身份识别，URI、参数与返回正文不保存。原生保留名缺少对应请求时，无法排除同名服务工具，操作类型保持未知；列资源目录与模板不计使用。

操作身份包含来源内任务、可靠轮次和调用/项身份。同一轮次的开始、完成与副本合并，其他轮次或新调用身份独立；没有身份的相同记录不按正文相等去重。明确分叉关系中，相同上游轮次及调用身份归回有记录的祖先任务，合并后续结果和证据；不因次数相同或路径相似而合并。祖先关系有环或身份不全时不推断复制。查询关联同轮次账本并取并集，不分摊成本或改写计量。

重放归并只修改派生结果；解析事实保持可重建。普通直接计量来源继续使用原有快速路径，有分叉时归并操作并重新同步对应投影，避免追加或重启恢复重复贡献。辅助索引借用已有身份，不缓存参数、URI、输出或另一份正文。

分叉关系只建立一次迭代先序区间索引，累计计量与操作共用。按精确身份及区间排序后，线性确定最早有记录的祖先，不为每条事件逐层追溯；操作按祖先批量合并元数据，物理依据一次排序去重。关系或事件规模为T、E，物理依据为P时，额外工作为O((T+E)log(T+E)+PlogP)，临时索引不复制正文；解析和查询仍保有安全事实，不承诺恒定内存。循环关系及其后代无法建立祖先区间，保留计量和操作并公开forkAncestryCycle，不互相删除成零。

调用自身的标准身份直接查操作表，仅为不同的项/调用身份保存别名映射，避免重复常驻和落盘。追加及索引重启仍按同一身份解析，已有读取版本不变。

静态复查通过与自然后续采用分开。后续观察只按本页历史记录、原复查时间、当前授权物理对象及来源/项目，单次遍历固定用量视图的规范操作；同一对象的多个复查时刻分别核对。MCP归属还须检查完整当前清单中同来源、同名且适用于该项目的物理声明，不由处理记录分页排除竞争声明；歧义事件不计数，无可归属记录时保持不可用。最后时间按真实时间比较，不按RFC3339字符串排序。仅保留每条处理记录的计数、最后时间与所选版本，不再复制账本、正文或执行回执，不持久写入派生观察，也不重建处理时间。

原生文件读取或MCP尝试没有可靠内容版本，因此已有关联事件只能说明版本未知，不能确认采用或节省。无事件只说未观察到，不宣称闲置；记录不可用和未适配运行事件单独标不可用。不为验证效果启动模型。把静态通过当采用会混淆事实，另建执行回执会重复Codex职责，均不采用。

## 考虑过的方案

按工具前缀关联会被名称歧义误导；按文件读取或目录查询计调用不符合使用语义。按内容相同合并重试会少计独立尝试。保留原生身份并区分操作类型增加少量元数据与归并工作，但不需要常驻采集器或执行模型来验证。

## 影响与验证

适配器版本为 `codex-rollout-3`；配置计数增加资源读取，使用次数为已观察工具调用与资源读取之和，缺完整覆盖不补零。当时处理库选择 `user_version=3`，旧布局拒绝且保留，不迁移；当前记录格式和版本见 [core README](../../../../core/README.md)，本记录不将当时验收延伸到新格式。

已按 Codex 0.160.0 的[协议](https://github.com/openai/codex/blob/rust-v0.160.0/codex-rs/protocol/src/protocol.rs)、[持久项](https://github.com/openai/codex/blob/rust-v0.160.0/codex-rs/protocol/src/items.rs)、[写入策略](https://github.com/openai/codex/blob/rust-v0.160.0/codex-rs/rollout/src/policy.rs)和[资源请求处理](https://github.com/openai/codex/blob/rust-v0.160.0/codex-rs/core/src/tools/handlers/mcp_resource/read_mcp_resource.rs)核对。Hook 运行通知不是这些日志的持久事件，Skill 调用主要在遥测/扩展通知中；本改动不从文本内容重建缺失事件，也不代表 MCP 提示词、完整运行覆盖或自然采用已完成。合成真值、跨入口、追加/重启和浏览器验证见 Git 历史中的验证记录。
