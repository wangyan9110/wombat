# 决策记录：本地 Web 与共享前端

中文 | [English](2026-10-01-local-web.en.md)

Status: implemented

## 问题

产品已确定 GUI、CLI、CLI+Web 方向，桌面选定 Tauri 2。需要先交付可运行 Web 基础工程，同时让仍在编写的产品方案与技术接入分离；不能在浏览器重新实现 Rust 计量或把通用内核 dispatch 暴露为 HTTP。

## 决定

新增 `ui/`（React / TypeScript / Vite）与 `web/`（Node 本机宿主），复用生成契约与 `UsageClient`。`wombat web` 管理服务生命周期，浏览器通过 `client/http` 访问窄操作，未来 Tauri 为同一界面注入独立传输。具体边界、认证和资源限制以[架构](../../../development/architecture.md)为准。

Node 宿主复用已验证的本机内核通信和官方价格更新；不新增 HTTP 框架，使用 Node 标准 HTTP 服务。前端按新版 HTML/CSS 与渲染结构实现 React 页面，不迁移旧页面。全部输入与缓存命中率保留为内核派生字段，不改旧 input 的非缓存含义；目录/模型聚合与匹配排序由内核提供，避免 Web 和 CLI 口径分叉。目录证据不升级为项目注册事实，未实现的优化规则展示不可用状态。TUI 产品代码随后已移除，Tauri 工程未创建。

## 考虑过的方案

- Rust HTTP 宿主：可以减少运行时层次，但本轮需要迁移 Node 已有的进程、连接和受限下载逻辑，增加首条 Web 链路范围；留待有实际收益证据时评估。
- 仅交付桌面：不满足先落地 Web 的顺序；桌面框架仍保持已选 Tauri 2，不重新选型。

## 影响与验证

前端静态资产随 CLI 打包；运行 Web 仍需 Node26.4.0+。只能本机访问，启动令牌不是远程身份体系。实时版本过期必须刷新；关闭标签不退出 CLI。共享业务没有改变，来源仍只读。

合成宿主测试验证 Host/Origin/令牌、静态文件边界、请求大小、生成契约、范围、并发、进度和取消；真实 Rust 端到端测试比较 Web/CLI 120,000 Token 与金额并下钻到记录，验证退出后监听关闭。当前构建的完整验证及浏览器边界另见[进度](../../../project/progress.md)，不据此宣称 Tauri 或其他平台已验收。
