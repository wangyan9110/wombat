# Decision Note: Local Web and Shared Frontend

[中文](2026-10-01-local-web.md) | English

Status: implemented

## Problem

The product direction is GUI, CLI, and CLI+Web, with Tauri 2 selected for desktop. A runnable Web foundation must ship first while keeping technical integration separate from the revised product specification. Browser code must not reimplement Rust accounting or expose generic core dispatch over HTTP.

## Decision

Add `ui/` (React / TypeScript / Vite) and `web/` (Node local host), reusing generated contracts and `UsageClient`. `wombat web` owns service lifecycle; the browser uses narrow operations through `client/http`. A future Tauri host can inject its own transport into the same interface. The [architecture](../../../development/architecture.en.md) defines boundaries, authentication, and resource limits.

The Node host reuses verified local core communication and official price updates. It uses Node's standard HTTP server without adding an HTTP framework. React pages follow the revised HTML/CSS and rendering structure without migrating old pages. All-input totals and cache hit rates are core-derived fields; existing input retains its uncached meaning. Core grouping and matching-usage sorting keep Web and CLI semantics aligned. Directory evidence is not promoted to project registration; unimplemented optimization rules are shown as unavailable. TUI product code has subsequently been removed; no Tauri project is created.

## Alternatives Considered

- Rust HTTP host: could reduce runtime layers, but would require moving existing Node process, connection, and restricted download logic, expanding the first Web slice. Revisit when evidence establishes a practical benefit.
- Desktop-only delivery: does not meet the Web-first sequence. Tauri 2 remains the selected desktop framework; framework selection is not reopened.

## Impact and Verification

Static frontend assets ship with the CLI; Web still requires Node26.4.0+. Access is local only, and the startup token is not a remote identity system. Expired live versions require refresh; closing a tab does not exit the CLI. Shared business semantics are unchanged and sources remain read-only.

Synthetic host tests cover Host/Origin/token checks, static file boundaries, request size, generated contracts, scope, concurrency, progress, and cancellation. Real Rust end-to-end tests compare Web/CLI totals of 120,000 tokens and amounts, drill down to records, and verify listener shutdown. Complete verification and browser boundaries for the current build are recorded in verification records retained in Git history; these checks do not validate Tauri or other platforms.

The subsequent [TUI removal decision](2026-10-01-remove-tui.en.md) replaces the transitional terminal arrangement.
