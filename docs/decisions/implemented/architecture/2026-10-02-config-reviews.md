# 决策记录：配置测量与人工处理记录

中文 | [English](2026-10-02-config-reviews.en.md)

Status: implemented

## 问题

当前内容体量、历史读取次数和关联轮次用量是不同事实。用字符比例代替分词、将读取视为 Skill 调用，或把派生索引中的忽略状态当永久用户决定，都会产生不可验证结果。升级需要 Web/CLI 同口径的静态提醒与完整人工复查。

## 决定

Rust 对完整 UTF-8 AGENTS.md / SKILL.md 使用固定离线 o200k_base 普通文本基准，记录方法、内容指纹和适用边界；字节、Unicode 码点及描述字段分别测量。编码与依赖版本锁定，独立官方合成真值验证；无完整 MCP 定义、超限或失败保持未知。仅按方法/指纹缓存数字，不保留正文。准确目录项核验防止大小写不敏感系统误认 AGENTS.md。

静态格式、描述和文件体量提醒按对象合并，修复优先；阈值只为产品提醒，预算或不支持的 YAML 扩展不报宿主格式错误。建议身份绑定对象、来源、内容、问题和范围，避免忽略吞掉独立新问题。Web/CLI 并列调用生成 optimize v1，无统一 CLI 中转。

不可重建的用户记录独立放入 user-v1 SQLite，事务内核对 decisionRevision，重复确认不重复追加；派生配置缓存重建不能清除记录。人工编辑在产品外完成，直接复查时重采集；无法完整检查不标通过。首次观察保存原始依据，用户决定与检查结果分开，处理记录有独立身份。语言偏好通过只接受 zh/en 的独立窄接口原子保存。

## 考虑过的方案

字符比例不能提供分词真值，复用派生配置缓存保存忽略会在重建时丢失用户意图，因此采用独立分词和用户存储。Wombat 自建生成、改写、清理及恢复服务的方向已由[原生 Codex 交接](2026-10-03-native-codex-handoff.md)取代；检查与用户决定继续独立。闲置、MCP 故障和空间候选依赖完整观察或来源适配，不用演示补齐证据。

## 影响与验证

当前事件适配和资源边界由[契约](../../../development/contracts.md)维护，未完成验收由[未完成提案](../../proposed/product/2026-10-03-optimization-lifecycle.md)维护，不在本记录重复功能清单。源码不写 Agent 配置或执行其命令，索引和用户记录只写产品目录。

独立分词向量、失败/重试去重、全日期、固定读取版本、用户记录保留、新问题、复查故障与双入口一致性需要合成真值；采集基准报告耗时、峰值 Rust 内存和结果一致性。浏览器及平台结论只能由对应构建的证据支持。

正文独立测量、描述的产品提醒与标准问题分别判断；身份包含有效参数，复查不能让未知正文通过。用户库共享依据与 SQL 分页的取舍见[复查完整性决定](2026-10-02-rule-review-integrity.md)，不在此复制当前规则版本与字段清单。

建议价值与文本对比仅作展示，复用已有config evidence去重账本和固定usageRevision，不建立第二套费用关联算法。首次观察保留原始安全测量，首次复查据此建立比较基线，后续复查不能用更新后的item替换原始比较口径；不可比时保持未知。日期改变不重新检查当前配置，轮次往返保存原路由，关联金额/文本变化均不视为节省。
