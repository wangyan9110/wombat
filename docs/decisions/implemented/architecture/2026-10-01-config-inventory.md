# 决策记录：只读配置与复合读取版本

中文 | [English](2026-10-01-config-inventory.en.md)

Status: implemented

## 问题

四入口升级需要真实配置清单及与对话的关联。配置文件描述当前状态，日志只提供部分历史证据；混合两者可能把当前内容当作历史版本，或把同一回合重复计算成配置独占费用。

## 决定

配置采集和证据查询放在 Rust，Web 和 CLI 通过生成的配置v1契约并列消费，不要求统一CLI中转。只读取启动时授权根中的固定入口；规则、Skill和MCP分别保留身份和覆盖状态。仅以显式文件读取或原生server字段关联，工具前缀不认定唯一配置实例。

复合读取版本固定安全配置元数据与用量引用，最多8版/10分钟，保留期间不因普通15秒空闲退出服务。用量普通版本淘汰后，仍可通过配置保留的引用回到原回合。版本过期和服务重启明确报错，页面提供刷新。

本次采用有界内存版本与原子JSON元数据缓存，先交付只读闭环；没有为尚未交付的项目注册、估算及写入能力预建数据库表。文件读取保留独立证据口径，关联用量按计量记录去重，无法识别的状态保持未知。当前实现及资源边界以[配置契约](../../../development/contracts.md)为准。

## 考虑过的方案

[完整提案](../../proposed/architecture/2026-10-01-config-analysis-web.md)中的类型化SQLite配置/关联表、持久复合版本和增量索引继续保留为后续方案，本次未实施；当前每次证据查询遍历安全事实。统一CLI中转已按用户决定取消。内容Token估算需先验证分词器，因此当前仅返回真实字节数，不使用字符比例伪造估算。

## 影响与验证

配置查询不修改来源、不联网探测或执行MCP，也不保存配置正文、命令参数或环境值。最近成功元数据用于区分历史条目和读取失败，但不证明历史内容。传输取消隔离迟到结果，内核扫描只有资源边界，协作取消、增量关联缓存、项目注册和自动建议仍未交付。

Rust合成测试覆盖越权符号链接、循环、无命令执行、敏感值隔离、大小上限、日期和版本淘汰；Web/CLI端到端覆盖同口径、重复读取守恒、分页、版本变化和读取失败。当前验证与未验收平台见[进度](../../../project/progress.md)，不得将完整提案阶段整体标为已完成。
