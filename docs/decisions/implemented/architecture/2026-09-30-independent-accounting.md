# 决策记录：独立计量、计价与来源适配

中文 | [English](2026-09-30-independent-accounting.en.md)

Status: implemented

本记录从首版方案整理，记录日期为 2026-09-30；当前字段与支持范围以[架构](../../../development/architecture.md)、[来源用例](../../../development/adapters.md)和[价格参考](../../../reference/pricing.md)为准。

## 问题

用量必须能从汇总下钻到对话、轮次和计量，同时保留来源缺失、累计遥测、历史设置与价格条件。只有日报行的上游聚合结果无法恢复这些关联；绑定另一产品的内部类型和构建链也会限制后续 Agent 与展示入口。

首版曾研究 ccusage 20.0.24，固定提交 `ecb676cce27cb5dd0090c7804a5cecc35e8ba805`。其中[静态来源加载](https://github.com/ccusage/ccusage/blob/ecb676cce27cb5dd0090c7804a5cecc35e8ba805/rust/crates/ccusage-adapter-all/src/loader.rs)与[公共类型](https://github.com/ccusage/ccusage/blob/ecb676cce27cb5dd0090c7804a5cecc35e8ba805/rust/crates/ccusage-core/src/types.rs)提供了边界参考；该研究版本不是当前上游能力声明，也不是 Wombat 的运行或测试依赖。

## 决定

- Wombat 独立维护事实级账本、标准 API 等价计价与公共查询。构建和常规测试不依赖 ccusage 包、源码副本或对账；通用库依实际需求复用并保留许可。
- 来源采用 Rust 静态适配器注册。格式、身份、缓存语义、历史设置、重放与去重归适配器；公共查询消费统一事实。首版仅注册 Codex，测试专用异构来源只证明协议边界。
- 能力与实际字段可用性分开。日汇总来源不制造轮次；无明确关联的操作不分摊费用；单个来源失败保留其他来源的成功回执。
- 价表、确定性匹配与金额计算分层，使用锁定的十进制库。非缓存输入、缓存读取、缓存创建、输出不重叠，推理是输出子集。官方折算、来源 reportedCost、旧政策和订阅实付不得混为一类。
- 缺失、零、冲突与未计价明确区分；当前配置不能补历史模型或供应商。测试以独立合成真值和跨层守恒为依据。

## 考虑过的方案

| 方案 | 取舍 |
|---|---|
| 继续复用 ccusage 的内部加载、聚合与计价链 | 日汇总不足以表达 Wombat 的明细归属；私有类型和构建闭包会形成产品耦合，因此退出业务依赖 |
| 立即建设动态插件市场 | 首版只有一个生产来源，能力差异尚需用真实适配验证；静态注册已满足当前扩展需求 |

## 影响与验证

需要自行承担来源格式维护、历史兼容和官方价表更新成本。后续来源须通过能力差异、身份隔离和部分失败测试，不能仅添加菜单就宣称支持。

A01–A12 的边界与真值见[来源验收](../../../development/adapters.md)，金额条件见[价格参考](../../../reference/pricing.md)。首版的 67 项测试、跨层及全分页守恒、独立构建与安装结果见 Git 历史中的验证记录和[查询证据](../../../benchmarks/usage-v1-query-2026-09-30.json)；这些结果限定于记录时构建与语料，不代表所有 Agent 或全部历史格式兼容。
