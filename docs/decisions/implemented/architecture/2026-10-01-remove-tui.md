# 决策记录：移除 TUI 产品与专用工具

中文 | [English](2026-10-01-remove-tui.en.md)

Status: implemented

## 问题

产品保留 GUI、CLI 与 CLI+Web，新页面不迁移旧终端结构。本机 Web 已落地，继续维护 OpenTUI 会保留独立的渲染、FFI、依赖与验收链路。

## 决定

移除 TUI 模块、交互启动器、专用词条、预览/PTY 工具、CI 终端旅程及专用 Skill，结束独立终端维护链路。共享进度文案仍归属客户端语言模块。

CLI 默认输出文本，本机交互由 Web 提供，入口命令见 [CLI 指南](../../../guides/cli.md)。共享 Rust 与生成契约保留，桌面不由本次删除任务交付。格式读取遵循[当前格式决定](2026-10-03-current-format-only.md)，不保留旧快照兼容要求。

## 考虑过的方案

此前安排等桌面工程落地后再移除 TUI。用户明确要求现在删除，因此不再维护过渡终端。Git 中已推送的基线仍可追溯旧实现，历史进度与证据不作为当前能力。

## 影响与验证

旧终端快捷键、主题环境变量、FFI 启动及退役指南均移除。源码历史可追溯原实现，但不作为当前能力或操作入口。

验证覆盖默认命令在终端标识下输出文本、CLI/Web 共享内核、取消、构建、类型、模块边界、依赖许可及安装包。实际结果与平台边界见 Git 历史中的验证记录。
