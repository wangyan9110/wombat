# 决策记录：移除 TUI 产品与专用工具

中文 | [English](2026-10-01-remove-tui.en.md)

Status: implemented

## 问题

产品保留 GUI、CLI 与 CLI+Web，新页面不迁移旧终端结构。本机 Web 已落地，继续维护 OpenTUI 会保留独立的渲染、FFI、依赖与验收链路。

## 决定

按用户明确顺序，先把 Web 基线提交并推送为 `74ca1bb`，再删除 TUI 产品模块、交互启动器、专用字典、预览/PTY 脚本、CI 终端旅程和专用 HTML 到 OpenTUI Skill。共享进度文案保留在客户端语言模块。

无子命令的 `wombat` 与 `wombat usage` 一样输出用量文本；交互页面由 `wombat web` 显式启动。保留 Rust、生成契约、旧快照读取、CLI 和 Web，不创建 Tauri 工程。本记录取代[本地 Web 决策](2026-10-01-local-web.md)中的过渡 TUI 保留安排。

## 考虑过的方案

此前安排等桌面工程落地后再移除 TUI。用户明确要求现在删除，因此不再维护过渡终端。Git 中已推送的基线仍可追溯旧实现，历史进度与证据不作为当前能力。

## 影响与验证

旧终端快捷键、主题环境变量和 FFI 启动不再可用。终端指南保留退役说明和现有入口，避免历史引用失效；用户日志与产品数据目录不变。

验证覆盖默认命令在终端标识下输出文本、CLI/Web 共享内核、取消、构建、类型、模块边界、依赖许可及安装包。实际结果与平台边界见[进度](../../../project/progress.md)。
