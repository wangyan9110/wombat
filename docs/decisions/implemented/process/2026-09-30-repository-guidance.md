# 决策记录：仓库规则与双语确认

中文 | [English](2026-09-30-repository-guidance.en.md)

Status: implemented

## 问题

仓库原有规则集中在根文件，模块、文档和 Skill 的职责容易互相重述；中文文档和英文入口修改时也缺少同步证据。完整移植大型仓库的治理系统会增加当前项目不需要的维护成本。

## 决定

保留根文件的全仓规则，在实际模块、文档和 Skill 目录补充局部约定；各模块 README 说明公开入口。公开页面按各自目录配对英文，并用指定文件的确认记录与静态检查阻止无意失配。持久的设计理由用本目录记录，日常验证仍按改动范围选择。

## 考虑过的方案

- **只保留根文件**：规则与模块细节继续混在每次会话的基础上下文中，文档和 Skill 缺少就近归属。
- **整体复制 DeepSeek Harness 的目录、模板和所有校验**：它服务更大的插件仓库及完整双语语料，会给当前 Wombat 引入无对应内容的流程和批量迁移。

## 影响与验证

新增目录约定、双语配对和聚焦脚本；原有中文页面已按用途整理并补齐双语，配对清单不再有旧文档待迁移项。`repo:check` 检查规则、配对与公开引用，但不证明译文语义、产品行为或终端视觉；这些仍需人工审校及相应测试。
