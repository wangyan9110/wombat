# 终端样式核对

以组件结构、CSS最终生效规则和OpenTUI属性为核对依据；截图仅能辅助，不替代继承、坐标和状态检查。产品构建及测试不读取私有原型。

复用流程与排查经验维护在项目内 [html-to-opentui Skill](../.agents/skills/html-to-opentui/SKILL.md)，无需依赖个人技能目录。

## 已固化的规则

| 组件 | 布局与字体 | 森林主题颜色与状态 |
|---|---|---|
| 页头 | 品牌/斜线/标题分色，斜线普通字重；长标题由原生文本单行截断 | 品牌`#a9d6b3`，斜线`#65836c`，标题`#dbe9df` |
| 用量表日期行 | 日期/模型/强度与数值共用列；小计加粗 | 文字`#d4e6da`；默认底色`#1d3628`；选中底色`#2b4a35` |
| 模型行 | 日期标记和模型文字内缩；普通字重；数字列与表头/总计对齐 | 模型`#c3d8ca`，其余分项`#a8c1b0`，标记`#91b49c`；选中不覆盖子元素文字颜色 |
| 用量分组 | 同一天共用一条左边界 | 当前分组竖线`#71997c`；未选中行悬停`#294632`；选中优先于悬停 |
| 表格宽度 | 120列宽版数值使用整数固定列宽，模型使用余量；68–119列用五列版，日期/模型按1.1/1.8分配 | 数值列保留九位整数及分组逗号，金额列保留中文表头；超长内容仍由OpenTUI换行，此处是终端网格适配而非CSS比例直译 |
| 页面位置 | 最大120列，超宽终端居中；正文统一左右边距 | 主题不改变几何；80/120/160列检查真实组件坐标 |
| 对话列表 | 标题和金额加粗，上下文普通字重；行间分隔线 | 选中底色`#223b2b`、左侧`#71997c`，不同于用量表 |
| 轮次 | 整轮与展开记录共享左侧容器；轮内排序使用下划线 | 普通竖线`#35513e`，当前轮次`#8bb99a` |
| 操作记录 | 时间/名称/状态分列，普通字重；窄屏纵向排列 | 时间`#91aa98`、名称`#d4e7d9`、结果`#92aa99`；记录分隔线`#344b3a` |
| 计量记录 | 标签普通字重，Token/费用强调；分类费用原位展开 | 展开背景`#21392a`，不套用用量表的绿色选中填充 |
| 消耗条 | 使用原生Box的细实线下边框及百分比宽度，不填充整行色块 | 轨道`#31513b`，进度`#86c59a`；保留所在行的背景 |
| 页尾说明 | 快捷操作在上、说明在下；原位开合，说明独立滚动且保留记录选择 | 说明底色`#1a2e20`、左边线`#56765c`、文字`#9db6a6`、开合入口`#a8c8b0` |
| 筛选表单 | 页内原生Input/Select，宽屏双列、窄屏单列；其他筛选原位开合；编辑期间不重建输入控件 | 标签`#b6cdbd`、边框`#60866b`、字段底色`#203d2c`、文字`#d9eddf`；无色模式使用终端默认色 |

原型的像素间距需要映射到整数终端行列。高度达到30行的终端，用量行在实际内容上下各留一行，避免两行容器内单行文字产生半行居中的取整偏差；短终端使用零上下留白。模型列的内缩放在文字单元格内，避免整数舍入使数字列错位。所有位置、边框、滚动、鼠标命中均由OpenTUI计算和绘制。

周期按钮将圆角边框与内部选中底色分开，边框格保留页面背景。主导航按钮底边与容器分隔线共用一个终端行；这是对小于一行的浏览器间距所做的网格近似，避免生成额外一整行间隔。轮次内的排序按钮不使用该导航合并规则。

对话汇总按项目与时间、总Token与费用、模型与强度排列。森林主题总计使用`#e1eee3`，上下文使用`#9db6a6`，保留普通字重；普通终端文本不模拟浏览器局部字号。费用展开为一个原生换行区，分类按输入、缓存读取、缓存创建、输出、其中推理排列，每项Token紧随自身金额；推理不另加费用。分项使用`#b5cab9`，宽屏并列、窄屏换行，金额字符串不拆开。这保留了用户要求的Token与费用相邻，而不是将所有费用拆成另一个远离Token的行。

页尾说明使用原生布局高度，上限为内容区55%；短说明按实际换行后的原生子节点高度收缩，长说明在ScrollBox内滚动。打开说明保留正文和当前记录，关闭后恢复选择。

价表以原生表格/两列卡片呈现，模型`#dbeee0`加粗，费率`#c2d9c9`普通字重，选中底色`#223b2b`，分隔线`#2d4534`。卡片标签使用`#91a897`，标签与费率通过原生布局对齐。详情沿用说明区背景，来源为简短链接文字，使用`#a7d4b2`下划线及原生终端链接。按模型读取长上下文阈值，不沿用固定示例阈值；具体可见模型来自本地价表。

## 字体边界

终端UI可以指定普通/粗体、颜色和下划线，不能通过普通文本协议为每个组件设置浏览器的`font-family`、`font-size`或650/750等连续字重。字体家族与字号来自运行它的终端。代码层面只对设计中需要强调的标题、金额和小计加粗；模型名、日志名称与操作结果保持普通字重。不自动修改用户的终端全局字体配置。

## 验证

`tui/tests/fidelity.test.ts`使用OpenTUI原生测试渲染器检查字体属性、单元格颜色、悬停/选中转移、列坐标、居中、轮次容器、0%/50%/100%细线消耗条和无色模式。细线占用一行布局，但绘制的是边框笔画，不是整格背景；实际笔画粗细由终端字体决定。`scripts/preview-usage-terminal.ts`可在明确指定的仓库外目录输出字符、单元格样式及组件几何，便于按代码核对。

这些检查不是任意浏览器CSS的完整兼容证明，也不代表已完成所有页面和状态的视觉验收。最新验证与未完成项见[实施跟踪](implementation-tracker.md)。
