# 使用本机 Web 面板

中文 | [English](web.en.md)

先按[安装指南](installation.md)安装 Wombat。Web 面板读取本机 Codex 记录。

## 打开 Web

1. 运行：

```sh
wombat web --open
```

2. 浏览器未自动打开时，使用终端输出的完整地址。
3. 停止 Web 宿主时，在该终端按 Ctrl+C。

关闭浏览器标签页不会停止宿主。宿主重启后，需要使用新的链接。

## 查看结果

概览展示用量趋势、项目与模型汇总，以及周期比较。任务页提供任务统计、轮次详情和已记录的耗时。配置页面展示指令、扩展、检查结果和处理记录。预算设置提供提醒与已结束周期的复盘。

页头的「配合 Skill 使用」显示实际发现的调用名称和提问示例。「接入与采集」区分发现、Hook 注册、信任和事件接收。Skill 已安装不代表首次读取已完成。

## 处理读取失败

- 没有出现任务时，先完成一项 Codex 任务，再选择「更新数据」。
- 读取失败时，打开「数据来源」，选择「重试」。
- 检查其他项目的配置时，在「数据来源」中添加项目目录。

首次读取期间仍可使用已有记录。耗时展示已记录的活动、重叠和覆盖缺口，不表示模型内部纯推理时间。

## 限制

宿主只监听回环地址。浏览器在会话内保存访问令牌。不支持远程部署。

Token、API 等价估算金额和账户额度分别展示。未知值不等于零。数据和联网限制见[隐私说明](../reference/privacy.md)与[计价说明](../reference/pricing.md)。
