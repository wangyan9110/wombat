# Retired terminal interface

[中文](terminal.md) | English

The OpenTUI product interface was removed on 2026-10-01. Bare `wombat` now prints usage text, just like `wombat usage`. Use `wombat web` and open the printed link for interactive pages.

See the [CLI guide](cli.en.md) and [frontend scope](../../ui/README.en.md). Historical terminal screenshots, test records, and development tools do not establish current functionality.
