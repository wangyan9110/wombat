# 终端使用

中文 | [English](terminal.en.md)

使用 Node.js 26.4.0 或更新版本，在交互终端执行 `wombat`。界面由独立 `tui/` 模块使用 OpenTUI 绘制；CLI 自动提供 FFI 参数。首次使用建立本机 Codex 索引，进入用量或对话时等待本次读取；主列表约每秒检查更新，保留选择和滚动。筛选草稿、费用展开与下钻期间保持当前视图。R 同步并保存不可变快照，显式 `--snapshot` 打开历史快照时不自动刷新。非 TTY 默认执行用量查询。

启动时使用 `--lang zh` 或 `--lang en`，主界面和读取期间按 L 切换。筛选和价表继承当前语言，原始标题保持原文；优先级与边界见[产品语言](../i18n/product.md)。

## 导航与查看

首页只有“用量 / 对话”。用量默认显示时段分布，日报近30个自然日、周报本月及之前5个月、月报本月及之前11个月，均截止今天。切换报表恢复该粒度的默认范围，保留模型与项目；F → 时间可以改为预设或自定义范围。分布条使用整个查询范围的最大值作为刻度，占比使用整个范围的总量；翻页不改变刻度、占比或峰值。峰值可直接进入相关对话，未知金额不填成零。

M 或指标按钮切换 Token／估算金额，V 或展示按钮切换分布／明细，S 或排序按钮切换最近日期／消耗优先。明细保留日期小计、模型及推理强度；选择时段或模型进入相关对话。对话按完整对话的消耗或最近活动排序；从报表进入时同时展示所选范围与完整对话用量，A 返回全部对话。轮次始终包含完整对话，金额占比使用完整对话的已计价金额。D 查看该对话完整日期范围的日报。

方向键选择，Enter 进入或展开，N/P 翻页，B 或 Esc 返回，Tab 或 1/2 切入口，Q 退出。返回恢复筛选、分页、选择和展开；两个入口保留独立主视图状态。读取时 X 或 Esc 取消，取消或读取失败后进入恢复页面，不把旧结果当成本次结果展示；Ctrl+C 取消并退出。加载图形只表示正在工作，阶段文字来自真实读取进度。

用量和对话列表的方向键可以跨页选择；Home/End 滚到当前页首尾，End 可查看范围合计。缩放会调整页容量并保留选中记录，日期明细组不拆页。重复点击当前周期保留日期筛选；切换指标或对话/轮次排序保留选中对象和已展开记录。周期和指标按钮使用完整字符边框；表格采用共享整数字格列宽，长模型名由原生组件换行。

## 筛选

F 打开同页筛选表单。用量先展示时间：随报表、今天、近30天、近半年、近1年、本周、本月及自定义。自定义显示起止日期，至少填写一项；模型、强度、项目和时区收在“其他筛选”。对话筛选展示搜索和项目，应用后清除从报表带入的时段、模型和强度条件。

宽屏双列，窄屏单列；Tab / Shift+Tab 切换字段，文本直接输入，时间、项目、模型和强度按 Enter 原位展开选项。Ctrl+S 或点击“应用”提交，Esc 放弃草稿；下拉打开时第一次 Esc 只关闭选项并恢复原值。文本框中的按键不触发主页面快捷键，切入口丢弃未应用的草稿。项目和模型候选覆盖当前快照的来源范围，不限于当前页或已选日期；同名项目保留完整路径。读取候选失败时显示错误并保留手动输入。

下拉标记与焦点边框区分当前字段；关闭下拉且焦点不在文本框时，L 切语言、T 切主题并保留草稿。价表也支持 L 切语言；展开的模型依据是独立阅读区域，点击正文不会折叠模型行。

## 呈现与数据边界

界面使用终端备用屏，页头与键盘提示固定，退出恢复原终端。工具栏、表头、记录、总计、操作与说明共用正文滚动区域；筛选按钮随表单滚动。品牌、版本和入口位于首行，标题与范围另行展示。明细数字右对齐；40列中模型与强度独占一行并允许长名称换行，日期保持完整，80列保留日期、模型、强度、Token与金额，120列展示分类表格。更宽窗口将120列内容居中。标题和工具名称仅作文字清洗，不执行控制序列或命令。

轮次展开后展示时间／消耗排序和记录，计量可继续展开分类 Token 与金额；操作不分摊费用，消耗排序时操作仍按时间排列。日期按所选时区和展示语言格式化，跨年补年份；同日轮次内省略重复日期，只有日期的记录不补时间。中文数量使用万/亿，英文使用 K/M 等紧凑数字，分类明细保留完整数值。

费用使用标准 API 等价单价估算，未知显示“费用未知”，部分金额加星号。金额占比在部分计价时表示占已计价小计，金额视角另列未计价 Token；无法确认的数量保留未知。点击正文末尾“数据说明 / 金额依据”或按 C 展开说明，方向键滚动正文，点击或 Esc 收起并保留选择。? 直接打开完整价表。

内存渲染、颜色/几何核对及真实 PTY 交互分别验收，范围见[支持矩阵](../reference/support-matrix.md)和[进度](../project/progress.md)。终端测试使用合成数据，不读取私人对话；字符网格不能与浏览器像素逐点等同。

## 价表

? 或 U 查看本地完整模型价表。点击按钮或按 S 切换标准／长上下文档；Enter 展开别名、适用阈值和官方来源，↑↓逐模型选择，N/P翻页，Esc返回。宽屏为表格，窄屏为两列价格卡片；“未单列”不按零计算，无长上下文档显示“—”。“价格口径”可展开估算说明。官方来源使用终端原生链接，点击支持取决于终端。价表页 U 显式联网更新，失败保留现有价表；返回主列表后自动同步新价格，R 可另存快照，旧快照金额保留。

## 主题

默认森林绿，T 在森林绿、午夜蓝、纸张浅色、琥珀终端间切换，当前打开期间保留选择。用环境变量固定默认主题：

```sh
WOMBAT_THEME=forest node dist/wombat.js
WOMBAT_THEME=midnight node dist/wombat.js
WOMBAT_THEME=paper node dist/wombat.js
WOMBAT_THEME=amber node dist/wombat.js
```

旧 `graphite` 名称兼容映射至午夜蓝。`NO_COLOR=1` 关闭颜色，选中结构保留。主题不改变数据或布局，无效名称使用森林绿。

开发者在构建客户端后运行 `corepack pnpm --filter @wombat/tui test`；真实终端验收另运行 `corepack pnpm smoke:terminal`。
