# 终端使用

中文 | [English](terminal.en.md)

使用 Node.js 26.4.0 或更新版本，在交互终端执行 `wombat`。界面由独立 `tui/` 模块使用 OpenTUI 绘制；所需 FFI 参数由 CLI 启动入口处理，无需手工添加。首次使用自动建立本机Codex索引；已有索引先显示已提交数据，随后自动同步。主列表约每秒检查更新，保留选择和滚动；编辑筛选、费用展开与下钻期间保持当前视图。按R同步并保存不可变快照。显式 `--snapshot` 打开历史快照时不自动刷新。非 TTY 默认执行用量查询。

启动时使用 `--lang zh` 或 `--lang en`，用量/对话主界面按 L 切换。筛选和价表继承当前语言，原始标题保持原文；优先级与边界见[产品语言](../i18n/product.md)。

## 导航与查看

首页只有“用量 / 对话”。用量按日、周、月查看：默认日报近7天、周报本周及之前3周、月报本月及之前11个月，均截止今天。切换报表自动调整默认范围；手动日期筛选保持不变，F → 时间 →“随报表”恢复自动范围。选择日期或模型分项进入相关对话。对话按消耗或最近活动排序，回车原位展开轮次，再查看记录和分类费用。返回恢复筛选、分页、选中和展开位置；“此对话用量”查看跨天的完整范围。

主要操作显示在内容下方，导航按键固定在页尾。方向键选择，回车进入或展开，Esc 返回，Tab 或 1 / 2 切入口，Q 退出。用量行按 Enter 直接查看相关对话，V 原位展开分类费用。Ctrl+C 可取消读取并退出，不提交未完成快照。

## 筛选

F 打开同页筛选表单。用量先展示时间，选择自定义后显示起止日期，至少填写一项；模型、强度、项目和时区收在“其他筛选”。对话筛选展示搜索和项目。宽屏双列，窄屏单列；Tab / Shift+Tab 切换字段，文本直接输入，时间、项目、模型和强度按 Enter 原位展开选项。Ctrl+S 或点击“应用”提交，Esc 放弃草稿；下拉选项打开时，第一次 Esc 只关闭选项并恢复原值。文本框中的字母和数字作为输入，不触发主页面快捷键。点击另一个入口会丢弃未应用的筛选。项目和模型候选覆盖当前快照的来源范围，不限于当前页或已选日期；相同名称的项目保留完整路径。读取候选失败时会显示错误，并保留手动输入。

## 呈现与数据边界

界面使用终端备用屏，页头与页尾固定，退出恢复原终端。日期小计、模型分项和总计采用同列数字右对齐；滚动到模型分项时保留日期，选择未离开可见区域时不推动列表。40 列采用多行，80 列保留日期、模型、强度、Token 与金额，120 列展示分类表格；更宽窗口将120列内容居中。对话标题和工具名称仅作文字清洗显示，不执行控制序列或命令。

对话详情在页头展示原生标题。轮次消耗与占比条并列，展开后直接展示“时间顺序 / 消耗优先”；选择该行回车切换。模型用量可继续展开分类 Token 和金额，工具操作按实际记录显示。同日轮次内省略重复日期，跨日保留日期；只有日期的记录不补时间。

日期按当前时区和展示语言格式化，跨年补年份。Token 保留通用写法；中文使用万/亿，英文使用 K/M 等紧凑数字，分类明细保留完整数值。费用紧随用量；未知显示“费用未知”，部分金额加星号。? 在当前页尾展开金额依据和必要的数据说明，方向键滚动说明，? 或 Esc 收起，不改变列表选择。

OpenTUI 迁移验收正在进行，以上为当前交互设计和源码行为；实际通过范围见[支持矩阵](../reference/support-matrix.md)、[实施跟踪](../project/status.md)和[进度](../project/progress.md)。历史渲染器的预览和 PTY 记录不代表新界面已经通过同等验收。终端测试使用合成数据，不读取私人对话。

## 价表

用量页或金额依据中按 U 查看本地完整模型价表。点击按钮或按 S 切换标准／长上下文档；Enter 展开别名、适用阈值和官方来源，↑↓逐模型选择，N/P翻页，Esc返回原页面。宽屏为表格，窄屏为两列价格卡片；“未单列”不按零计算，无长上下文档显示“—”。官方来源使用终端原生链接，是否可点击取决于终端支持。价表页按 U 显式联网更新，失败保留现有价表；返回主列表后自动同步新价格；R可另存快照，旧快照金额保留。

## 主题

默认森林主题，按 T 在森林、浅色、石墨之间切换，当前打开期间保留选择。用环境变量固定默认主题：

```sh
WOMBAT_THEME=forest node dist/wombat.js
WOMBAT_THEME=paper node dist/wombat.js
WOMBAT_THEME=graphite node dist/wombat.js
```

`NO_COLOR=1` 关闭颜色，选中箭头与结构保留。颜色采用独立的语义主题定义，包含品牌、标题、数值、背景、正文、弱化文字、分隔线、强调色、选中态、小计和明细背景，不改变数据或布局。无效主题名使用森林主题。

开发者可在构建客户端后运行 `corepack pnpm --filter @wombat/tui test`。OpenTUI 内存渲染与模拟键鼠测试用于组件回归；视觉对照和真实终端交互另行验收。
