# 产品语言与文案

中文 | [English](product.en.md)

本页定义 CLI/Web 的展示语言。文档配对由[双语文档流程](README.md)管理。

## 使用

```sh
wombat --lang en
wombat usage --lang zh
wombat prices --lang en
WOMBAT_LANG=en wombat --help
```

语言优先级为 `--lang`、`WOMBAT_LANG`、系统语言、中文兼容默认值。支持 `zh` / `en` 及其地区标签。系统语言依次取非空的 `LC_ALL`、`LC_MESSAGES`、`LANG`，均未设置时使用运行环境的语言；`C` / `POSIX` 使用英文。显式指定不支持的语言报参数错误，无法匹配的系统语言回退中文。

Web 使用页头或详情内语言按钮切换，保留页面、筛选、弹窗、焦点及来源原文。优先读取启动链接的显式语言（来自 --lang 或 WOMBAT_LANG），否则读取本机 `user-v1/language.json`，再回退标签会话选择、浏览器语言。切换经受限偏好接口持久化，服务换端口或重启仍有效；保存失败显示重试提示。CLI 继续使用参数和环境变量，不读取该 Web 偏好。

## 模块边界

- `@wombat/client/locale` 是独立的纯 TypeScript 公开入口，不依赖 Node、React 或 Rust。它提供 `LocaleRuntime`、`resolveLocale`、类型化 `t`、不可变状态及订阅；每个 CLI 进程或浏览器页面使用独立展示实例。
- `client/src/locale/zh.ts` 与 `en.ts` 保存完整消息，以功能前缀划分键；英文键集合由中文键集合约束。参数名从中文模板推导，双语参数一致性另由检查脚本验证。正文参数按原值插入，不递归解析或翻译。
- CLI 负责解析语言参数和环境变量；Web 读取语言状态。模块级标签使用延迟读取，避免启动时捕获旧语言。界面操作使用稳定标识，不能根据翻译后的文字判断业务动作。
- 语言影响帮助、提示、标签、日期和紧凑数字展示。JSON 字段、错误码、模型标识、来源标题、用户内容及用量/金额不翻译。已知内核与宿主进度在展示层映射；未知内核诊断与来源问题原样保留。
- 数量消息使用完整模板及原生 `Intl.PluralRules` 选择单复数；零、未知及两个独立计数分别处理。月桶展示本地语言的年月，不将日历日期转为宿主时区。配置指令 Token 标为估算，列表大小使用 KiB（1,024 B），保留准确字节证据并按原始数值排序。

## 验证与限制

`corepack pnpm i18n:check` 检查字典键和参数，并检查 CLI/Web 的中文字面量及部分英文文案属性。它使用 TypeScript 语法树，跳过注释；它不能判定译文质量或识别所有动态拼接的英文文案。新增消息仍须人工审校。

`corepack pnpm test:repo` 验证检查器的故障样本；模块测试覆盖语言优先级、运行时切换、展示格式化；构建后的端到端测试确认语言不改变共享内核数据。范围为中英 CLI/Web 展示，未增加任意语言插件、通用语法表达式语言、从右到左布局、文档网站或内核诊断全文翻译。
