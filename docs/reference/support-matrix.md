# 支持矩阵

中文 | [English](support-matrix.en.md)

当前包含用量、对话与只读配置分析。核心及原有 CLI/TUI 的验证记录见[进度](../project/progress.md)。当前入口为 CLI 与本机 Web，TUI 已移除，当前状态见[实施跟踪](../project/status.md)；历史终端测试不替代新界面验收，历史命令不再视为当前支持。

| 能力 | 实现范围 | 边界 |
|---|---|---|
| 来源 | Codex 活跃与归档 JSONL，多根隔离 | 其他 Agent 仅有通用协议和测试适配器，无产品接入 |
| 用量 | 日 / 周 / 月，默认近30天 / 6个月 / 12个月；分布/明细、Token/估算金额视角；时区、模型、强度、项目、对话筛选 | 默认包含当前周期且截止今天，CLI显式日期优先，Web 切周期保留日期；按记录时间，未知日期不分配虚构日期 |
| 对话 | 跨天、跨模型；搜索、排序、固定快照分页 | 标题仅原生索引，不生成用户提问摘要 |
| 轮次 | 全对话汇总、来处匹配用量、匹配轮次筛选与定位分页、Token/金额占比、其他记录 | 缺失关联不按时间猜测 |
| 记录 | 按时间或消耗排序；计量分类与实际操作 | 工具调用不独立分摊Token/金额，无正文回放 |
| 价格 | 离线官方标准 API 折算、十进制分项、版本和依据；已核对 GPT-5.3-Codex、GPT-5.4/5.5、GPT-5.6 Sol/Terra、GPT-6 Sol/Astra 等价表模型 | 未公开标准 API 单价的 `codex-auto-review` 及缺历史模型证据的记录保留未知；非订阅实付 |
| 价表更新 | prices/status/update与Web 完整模型价表；标准/长上下文档、阈值/别名/来源展开；官方标准文本/Codex价格下载、验证、版本化保存 | 支持缺价自动检查与显式联网；失败15分钟/成功24小时限流，可关闭自动联网；下一实时版本/新快照生效，旧快照不重算；格式变化拒绝更新，未公开单价仍未知 |
| 旧快照 | v1/v2 用量与对话只读、原政策金额 | 缺轮次/强度保持不可用；不覆盖原文件 |
| 本机 Web | 概览/任务/配置/优化、统一用量详情、趋势/近期任务、筛选、价表、同步和取消、窄屏返回 | 仅 loopback；项目是授权目录证据；Tauri 宿主未交付 |
| 实时同步 | 追加游标、SQLite事务、单实例按需服务、文件通知/巡检、自动列表、fresh/cached/watch、完整核验 | Unix socket / Windows 命名管道共用服务逻辑；macOS实测，Windows待验收；无有效配置读取版本时约15秒闲置退出；短期版本最多8版/10分钟，持久MVCC与百万级资源目标未交付 |
| 展示语言 | CLI --lang/WOMBAT_LANG；Web 中英切换并持久化到本机产品数据目录 | [语言契约](../i18n/product.md)；来源内容与协议值不翻译 |
| 配置分析 | 准确命名 AGENTS.md 的有界发现；完整 UTF-8 字节/码点/固定方法 Token，Skill YAML 描述；原生 MCP 尝试次数，读取及去重关联用量独立 | 授权根；无历史内容、加载优先级、可靠 Skill 调用/MCP资源事件和 MCP定义测量；超限不伪造；[契约](../development/contracts.md) |
| 优化处理 | 对象级静态格式/体量提醒、待处理/记录、忽略/恢复、人工编辑标记与重采集复查；记录不随索引重建删除 | 无连续观察闲置判断、MCP故障、空间清理、自动写入、撤销或预计节省 |
| 自动化 | refresh/usage/threads/turns/steps JSON v3；配置、优化与偏好 JSON v1 | 无 TTY；窄接口，无任意执行 |
| 故障 | 来源同步独立回滚、保留旧贡献且健康来源继续更新；明确partial、重启恢复、快照哈希、刷新锁、取消 | 原日志多文件不是原子一致快照 |
| 读取资源 | 完整大行、尾行等待；共享事实/依据、紧凑索引、有界版本查询缓存、分组汇总、增量更正/撤销 | 十万计量及十万操作固定语料已测；来源归并仍持有全量安全事实，非恒定内存；百万级/长期目标未验收 |
| npm 分发 | 单包内置 macOS arm64/x64、Linux glibc arm64/x64、Windows x64 内核；按目标选择；五平台 CI 与安装门禁 | 本机仅验证 macOS arm64；其他目标等待托管 CI 实测，Linux 基线为 Ubuntu 24.04，不含 musl/Windows ARM64；候选不代表已发布 |

来源具体边界与独立验收用例见[适配器用例](../development/adapters.md)，价格规则见[计价文档](pricing.md)。

未交付：其他平台安装验收、其他 Agent 生产适配器、全量历史格式保证、模型质量/因果诊断、实际订阅账单、桌面、永久后台监控、配置写入与修复、HTML 报告和证据包导出。新开发不重新引入废弃产品入口。

阈值修订：Skill全文与正文独立测量；description产品提醒/规范上限分级，规则v2与参数记录兼容旧缓存/忽略。加载预算、30天完整观察、14天worktree运行/保护/恢复适配未支持，覆盖不足不生成建议，见[规格](../project/config-upgrade.md)。

优化建议已接入真实关联记录查询，支持次数/轮次Token/API估算金额同屏、准确轮次往返保留筛选，以及人工复查的可比文本测量。日期仅筛关联记录；覆盖缺口、无关联和未知用量显式保留，不显示演示收益或自动执行。

首次运行与静态规则当前范围见[规格](../project/startup-rules.md)：Web外壳/偏好、等待/旧结果、宿主后台补价、任务元数据发现及明确存储故障；完整段落/列表的精确重复、用户声明链与identity-v1副本漂移经CLI/Web同口径公开。声明不代表实际加载，Hook有效注册/实际注入/执行仍未有适配；资源超限不能判通过。

规则复查与共享配置采用static-config-v4：同机同路径对象聚合，逐来源证据和重叠授权成员保留；未知适用条件及缺失声明不能通过。用户处理记录共享依据并在数据库分页，旧记录事务迁移；[契约](../development/contracts.md)说明兼容和资源边界。
