# 支持矩阵

中文 | [English](support-matrix.en.md)

首版范围为用量与对话。核心及原有 CLI/TUI 的验证记录见[进度](../project/progress.md)。根级模块与 OpenTUI 迁移已进入整链路验收，当前状态见[实施跟踪](../project/status.md)；历史终端测试不替代新界面验收，历史命令不再视为当前支持。

| 能力 | 实现范围 | 边界 |
|---|---|---|
| 来源 | Codex 活跃与归档 JSONL，多根隔离 | 其他 Agent 仅有通用协议和测试适配器，无产品接入 |
| 用量 | 日 / 周 / 月，默认近30天 / 6个月 / 12个月；分布/明细、Token/估算金额视角；时区、模型、强度、项目、对话筛选 | 默认包含当前周期且截止今天，CLI显式日期优先，TUI切周期恢复默认范围；按记录时间，未知日期不分配虚构日期 |
| 对话 | 跨天、跨模型；搜索、排序、固定快照分页 | 标题仅原生索引，不生成用户提问摘要 |
| 轮次 | 全对话汇总、来处匹配用量、Token/金额占比、其他记录 | 缺失关联不按时间猜测 |
| 记录 | 按时间或消耗排序；计量分类与实际操作 | 工具调用不独立分摊Token/金额，无正文回放 |
| 价格 | 离线官方标准 API 折算、十进制分项、版本和依据；已核对 GPT-5.3-Codex、GPT-5.4/5.5、GPT-5.6 Sol/Terra、GPT-6 Sol/Astra 等价表模型 | 未公开标准 API 单价的 `codex-auto-review` 及缺历史模型证据的记录保留未知；非订阅实付 |
| 价表更新 | prices/status/update与终端完整模型价表；标准/长上下文档、阈值/别名/来源展开；官方标准文本/Codex价格下载、验证、版本化保存 | 支持缺价自动检查与显式联网；失败15分钟/成功24小时限流，可关闭自动联网；下一实时版本/新快照生效，旧快照不重算；格式变化拒绝更新，未公开单价仍未知 |
| 旧快照 | v1/v2 用量与对话只读、原政策金额 | 缺轮次/强度保持不可用；不覆盖原文件 |
| 终端 | 独立 OpenTUI 模块、中英两入口、筛选、轮次/费用展开、页尾说明、四套主题；Node.js 26.4.0+ | macOS Apple Silicon 已验收40 / 80 / 120列、超宽居中、键鼠、缩放与退出；其他平台未验收，内核诊断可能保留原语言，桌面 GUI 未交付，Web 见下行 |
| 本机 Web | CLI 启停、用量/对话/轮次、来源、价表、日期/模型/强度筛选、深浅主题；真实进度与取消 | 仅 loopback；目录证据不等于项目注册；优化规则、Tauri 宿主未交付 |
| 实时同步 | 追加游标、SQLite事务、单实例按需服务、文件通知/巡检、自动列表、fresh/cached/watch、完整核验 | Unix socket / Windows 命名管道共用服务逻辑；macOS实测，Windows待验收；约15秒闲置退出；短期版本最多8版/10分钟，持久MVCC与百万级资源目标未交付 |
| 展示语言 | `--lang zh/en`、`WOMBAT_LANG`、系统语言；主界面 `L` 切换 | [语言契约](../i18n/product.md)；原始内容与 JSON 数据不翻译，无偏好文件 |
| 自动化 | refresh / usage / threads / turns / steps，JSON v3 | 无 TTY 可用；旧命令协议已移除 |
| 故障 | 来源隔离、明确partial、快照哈希、刷新锁、取消 | 原日志多文件不是原子一致快照 |
| 读取资源 | 完整大行、尾行等待；共享事实/依据、紧凑索引、分组汇总、增量更正/撤销 | 十万计量及十万操作固定语料已测；来源归并仍持有全量安全事实，非恒定内存；百万级/长期目标未验收 |
| npm 分发 | 单包内置 macOS arm64/x64、Linux glibc arm64/x64、Windows x64 内核；按目标选择；五平台 CI 与安装门禁 | 本机仅验证 macOS arm64；其他目标等待托管 CI 实测，Linux 基线为 Ubuntu 24.04，不含 musl/Windows ARM64；候选不代表已发布 |

来源具体边界与独立验收用例见[适配器用例](../development/adapters.md)，价格规则见[计价文档](pricing.md)。

未交付：其他平台安装验收、其他 Agent 生产适配器、全量历史格式保证、模型质量/因果诊断、实际订阅账单、桌面、永久后台监控、配置写入与修复、HTML 报告和证据包导出。新开发不重新引入废弃产品入口。
