未交付：完整优化闭环验收、其他平台安装验收、其他 Agent 生产适配器、全量历史格式保证、模型质量/因果诊断、实际订阅账单、桌面、永久后台监控、HTML 报告和证据包导出。新开发不重新引入废弃产品入口。

明确 Markdown 本地引用检查存在性/类型及授权边界，逐规则结果经 CLI/Web 公开；旧读取版本保留原观察，动态路径和访问缺口不报缺失。

阈值修订：Skill全文与正文独立测量；description产品提醒/规范上限分级，规则版本与参数随处理依据保存。加载预算、30天完整观察、14天worktree运行/保护/恢复适配未支持，覆盖不足不生成建议，见[规格](../project/config-upgrade.md)。

优化建议已接入真实关联记录查询，支持次数/轮次Token/API估算金额同屏、准确轮次往返保留筛选，以及人工复查的可比文本测量。日期仅筛关联记录；覆盖缺口、无关联和未知用量显式保留，不显示演示收益或自动执行。

复查通过的处理记录另显示待后续任务确认，按原复查时间和项目/来源核对自然关联记录，区分未观察到、版本未知与读取不可用。CLI/JSON和Web共享结果；文件变化不代表采用，正向声明或定向读取只形成近似“观察到使用”，不证明遵循Skill内容。精确调用及运行问题再现仍未交付。

首次运行与静态规则当前范围见[规格](../project/startup-rules.md)：Web外壳/偏好、等待/旧结果、宿主后台补价、任务元数据发现及明确存储故障；完整段落/列表的精确重复、用户声明链与identity-v1副本漂移经CLI/Web同口径公开。AGENTS.md已有Codex原生日志加载证据；Codex0.160.0文件声明的Hook项目注册状态已有观察适配，Unix已提供有界静态脚本引用检查；插件独立/内联JSON声明及原生已展开静态路径已按身份、文件版本和授权项目绑定。残留动态表达式保持未知，Windows命令及Hook实际注入/执行仍未完成；资源超限不能判通过。

按未发布首版仅维护当前格式，旧快照、旧索引和旧页面不提供迁移或兼容。

当前规则static-config-v7保留v4的复查与共享配置约束：同机同路径对象聚合，逐来源证据和重叠授权成员保留；未知适用条件及缺失声明不能通过。用户处理记录共享依据并在数据库分页，只初始化当前数据库格式，未知格式明确拒绝；[契约](../development/contracts.md)说明格式和资源边界。
