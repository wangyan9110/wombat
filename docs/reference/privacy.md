# 隐私与本地数据

中文 | [English](privacy.en.md)

本页说明当前隐私边界；数据目录与存储机制见[架构](../development/architecture.md)。

Wombat 无需 API Key，只读本地 Codex rollout 日志和标题索引，不修改 Codex 日志、配置、登录和安装。实时查询发现符合条件的用量缺价时，默认向固定的 OpenAI 官方地址下载价表；显式 `prices update` 也会联网。请求不携带本地日志、标题、路径、用量或凭据，但服务方可看到连接 IP 和 Wombat User-Agent；下载拒绝重定向并限制超时与响应大小。

设置 `WOMBAT_AUTO_PRICES=0` 关闭自动联网；`--cached`、固定快照及基础 `refresh` 不自动下载价表。显式 `prices update` 不受该开关限制。失败保留用量与价表，冷却及生效规则见[价格说明](pricing.md)。安装依赖所需的公共软件下载与产品查询分开。

派生索引与快照保留 Token 分类、价格依据、来源/对话/轮次身份、模型与推理强度、时间、项目、原生标题，以及安全操作字段（工具名称、文件路径、退出码、耗时、MCP server/tool）。原始用户消息、模型正文、完整命令参数、工具输出不进入快照或 Node 响应。模型、标题、路径和名称仍可能包含敏感信息，不应随意外发。

产品数据位于系统应用数据目录，可用 WOMBAT_DATA_HOME 指定。文件原子替换；Unix 创建私有权限，Windows 继承数据目录 ACL，应使用当前用户的私有目录。快照不是加密保险库。本版没有上传、全文回放、证据导出或任意执行能力。

来源目录会持续变化，单次刷新固定每个文件观察到的边界；部分失败、未完成尾行和无法确认的关联保留状态。工具调用没有独占Token时不伪造费用。官方 API 等价金额不代表订阅账单。

测试与公开仓库只使用合成语料。真实来源自测输出必须在仓库外，未经审查的 raw、真实对话与密钥不得写入测试或公开资料。历史用户决定、身份登记和恢复材料不随废弃功能清理删除。

授权根的配置全文仅在内存中读取、哈希和测量；派生配置缓存只存安全元数据。忽略/人工处理记录与语言偏好独立存于 user-v1，不随索引重建清除；记录仍含对象名称和路径，外发由用户决定。
