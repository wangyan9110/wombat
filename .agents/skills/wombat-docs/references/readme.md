# Root README review

Write root READMEs for first-time users. Put the content in this order:

1. Explain what Wombat does.
2. Show how to install and open it.
3. Describe the visible result and recovery steps.
4. Introduce the main uses and necessary limits.
5. Link help, contribution, security, and license information.

Keep source development separate. Put detailed platform support after the main workflow.

Describe user actions and results. Include installation layout, PATH changes, runtime composition, packaging, or internal verification only when readers need these facts to decide or act. Link only to user-facing owners.

Keep the README, repository About, Topics, and package description consistent with current capabilities. Do not use planned agents or unsupported behavior as keywords.
