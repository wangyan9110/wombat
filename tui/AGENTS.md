# 终端界面开发约定

本目录同时遵循[根目录约定](../AGENTS.md)及[开发约定](../docs/development.md)。公开入口与呈现限制见[终端模块说明](README.md)。

- 页面通过注入的 `UsageClient` 查询，筛选、汇总、计价和来源归属由内核负责；TUI 只维护导航、草稿、展开、滚动及显示格式。
- 使用 OpenTUI 原生组件和语义主题；布局与键鼠行为以当前代码、原生渲染测试和真实终端验证核对。浏览器原型的未验证部分不能宣称已还原。
- 没有直接文件系统、原始日志、内核进程或通用命令执行入口；新交互不得把业务规则藏在页面分支中。
- 改动布局或交互时使用合成客户端验证状态及原生渲染；涉及终端生命周期、宽度、缩放或退出恢复时补真实 PTY 旅程并写明范围。
